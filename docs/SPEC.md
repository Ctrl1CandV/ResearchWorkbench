# 个人研究平台行为契约

## 目标与范围

帮助研究生理解研究方向、分层阅读论文、建立 Agent 技术能力并筛选日常学术信息。

**当前首要价值（2026-09-21 初次授权，09-22 研究方向调整，SCAFFOLD-008 / 008.2）**：帮助论文积累少的研究生建立起步地图、控制学习曲线、完成第一批有效阅读。初期展示**两条**候选方向（主方向：输入/输出预算约束下的 Cross-Harness Agent Collaboration 机制与表示组合比较；第二条：代码智能体的修复正确性与验证），另两条（可信 RAG、图有害融合）延后不删除。

当前能力：首页五区；两条 active 与两条 deferred 方向的对象/现状/选择理由/限制；按重要性建议投入、按实际来源交付的分级阅读卡；统一阅读排版；13 条 Agent 技术路线（默认展示多智能体、RAG、浅图三条，其余保留为按需主干）；经典书目（`#/foundations`）；每日精选（工作日漏斗产出 + 历史工作日索引 + Crossref 实时登记发现）；本人阅读记录 v3（独立存储、仅本机）。

不做：自动认定本人已读、发表保证、账号/云端/打卡平台、无授权插件记录初始化、画像打分任何变体、无人值守定时抓取。

**「重排已批准研究方向」限制的修正（2026-09-21 用户明确授权）**：本轮将初期入口从三条改为两条并新增协作方向，被撤下的两条延后、不删除。此为一次性授权变更；此后仍不得无授权再改方向集合。

**2026-09-22 补充授权**：方向集合不扩大，主方向 id 保留；研究对象明确为隔离 harness、异构 Agent 在固定输入/输出 token 预算下持续完成复杂任务时，不同协作机制及具体表示策略组合的效果、成本和适用条件。共享状态、handoff、长期记忆、文档/wiki、检索与工件都是候选，不预设胜者；换手是切片，不是全题。路线是稀疏引导，不建设协议或实验平台。完整文字、选目与预算边界见 SCAFFOLD-008/00–02。

## 行为规约

- PF-01：首页与方向页分开，首页各区均有真实预览、用途和入口，不伪造个人进度。本人手动标记的"在读"条目可作为直达入口出现在首页（REWORK-007 §2）——这只引用用户自己的标记，不构成进度认定或统计。**补充（008.1）**：首页、方向列表、侧栏快捷入口只列 `status=active` 的方向；延后方向保留直达链接（页顶一行说明）与库内论文。每日精选区用途改为「感知前沿在做什么、用了什么方法，不是今天的阅读作业」。
- PF-02：方向包含具体研究对象、截止日期明确的现状、选择理由及限制；事实有来源，推荐是分析，不外传私人适配依据。
- PF-03：重要性、难度、论文类型独立；推荐深度不等于交付深度。只有摘要最多 quick，没有摘要只 entry；deep/standard 必须有相应正文依据。
- PF-04：三种深度的内容结构真实不同，类型决定章节组织；不增加空栏目或靠字数伪装精读。
- PF-05：正文/标题/操作/元数据字体明确；侧栏及主按钮不受全局链接色覆盖；长文、表格、来源、目录在桌面与手机可用。
- PF-06：技术路线不要求先选论文方向，不要求学完全部框架；资源标先修/权限/版本/核查层级，实践选学不阻塞阅读。**补充（008.1）**：技术页**默认**展示本里程碑三条技术路线（多智能体架构＝必学 / RAG＝按需 / 图＝浅尝）；原 T4 复用为 featured RAG，规范 id `tech-rag`，旧 `tech-t4` 只作读取别名、不复制第二条入口；其余 T1–T6 与其它支线归入「其他主干（当前不必先学）」，仍可点开、不删除数据。
- PF-07：引用关系有来源，编辑关联不冒充引用。论文时间与简报整理时间分开，失败不是零新增。
- PF-08：旧公开内容去重保留覆盖级别，旧本人记录保持同源可访问；新版只读写 v3，不读写 v1/v2。迁移与删除必须另获明确授权，先导出验证。
- PF-09：private/、.grad/、密钥与私人研究材料不进入公共资源。grad-companion 用于真实内容生产，网页展示不等于网页运行技能；AI 整理不标已读。
- PF-10：CCF 期刊与会议分开，不承诺创新或录用；测试、正文审查、视觉与真实交互验收分别如实记录。
- PF-11（新增，008.1）：起步卡首屏回答「讲什么 / 对当前路线的价值 / 带着什么目的」；本人看原文、看整理、跳过对应具体范围（readingActions 的 Preserve / Explain / Skip），Explain 必须有实际讲解（非空 inline blocks 或有效 sectionId 引用，二者其一），Skip 必须有理由；路线前后节点按 route 与 track 走，旧 paper.next 仅为延伸阅读、不覆盖路线导航。

## 每日发现固定契约（/api/discover）

实现权威在 `discovery.mjs`，行为由 `tests/discovery.test.mjs`、`tests/server.test.mjs` 逐项锁定：

- 仅三个固定主题白名单 query（agent=language model tool use / rag=retrieval augmented generation / peft=parameter efficient fine tuning），无用户自由文本、不接受任意 URL；参数变体一律 400。
- 窗口=最近 7 个 UTC 日登记（from-created-date），sort=created 倒序、rows=20、select 固定字段；严格日历校验（拒绝归一化），DOI/title 必需、DOI 去重。
- 超时 12s、响应 2MiB 上限、429/无效 JSON/非法结构均为明确错误，**无种子回退、不用旧缓存冒充今日结果**；缓存 15 分钟（保留原 fetchedAt，cached=true）；全局上游间隔 ≥3s；每主题每日最多 5 次真实尝试（成败均计），超限 503 不计次。
- Crossref query 为广泛 OR 匹配，必须按「标题+清洗摘要」做两组 AND 主题后置过滤；0 条是合法结果，不称穷尽。
- 文案边界：近期登记≠近期发表；论文登记时间与简报整理时间分开；动态条目不进入内容库、不写入个人记录；仅用户点击才请求。
