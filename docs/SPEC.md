# 个人研究平台行为契约

## 执行方案

### 目标与范围
帮助研究生理解研究方向、分层阅读论文、建立Agent技术能力并筛选日常学术信息。

本次范围：独立平台首页展示四工作区及使用方式；三个已批准方向的对象/现状/选择理由/限制；按重要性建议投入、按实际来源交付的分级阅读卡；统一阅读排版；六条独立Agent技术主干；旧版公开内容作选读支线。

不做：本轮应用实施、私人数据迁移、旧版删除、自动认定本人已读、发表保证、账号/云端/打卡平台、无授权插件记录初始化、重排已批准研究方向。

### 行为规约
- PF-01：首页与方向页分开，首页四区均有真实预览、用途和入口，不伪造个人进度。
- PF-02：方向包含具体研究对象、截止日期明确的现状、选择理由及限制；事实有来源，推荐是分析，不外传私人适配依据。
- PF-03：重要性、难度、论文类型独立；推荐深度不等于交付深度。只有摘要最多quick，没有摘要只entry；deep/standard必须有相应正文依据。
- PF-04：三种深度的内容结构真实不同，类型决定章节组织；不增加空栏目或靠字数伪装精读。
- PF-05：正文/标题/操作/元数据字体明确；侧栏及主按钮不受全局链接色覆盖；长文、表格、来源、目录在桌面与手机可用。
- PF-06：技术路线不要求先选论文方向，不要求学完全部框架；资源标先修/权限/版本/核查层级，实践选学不阻塞阅读。
- PF-07：引用关系有来源，编辑关联不冒充引用。论文时间与简报整理时间分开，失败不是零新增。
- PF-08：旧公开内容去重保留覆盖级别，旧本人记录保持同源可访问；新版首批不读写v1/v2。迁移与删除必须另获明确授权，先导出验证。
- PF-09：private/.grad/密钥与私人研究材料不进入公共资源。grad-companion用于真实内容生产，网页展示不等于网页运行技能；AI整理不标已读。
- PF-10：CCF期刊与会议分开，不承诺创新或录用；测试、正文审查、视觉与真实交互验收分别如实记录。
