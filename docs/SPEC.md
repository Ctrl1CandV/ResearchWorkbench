# 个人研究平台行为契约

## 目标与范围

帮助研究生理解研究方向、分层阅读论文、建立 Agent 技术能力并筛选日常学术信息。

当前能力：首页五区；三个已批准方向的对象/现状/选择理由/限制；按重要性建议投入、按实际来源交付的分级阅读卡；统一阅读排版；六条独立 Agent 技术主干；经典书目（`#/foundations`）；每日精选（工作日漏斗产出 + 历史工作日索引 + Crossref 实时登记发现）；本人阅读记录 v3（独立存储、仅本机）。

不做：自动认定本人已读、发表保证、账号/云端/打卡平台、无授权插件记录初始化、重排已批准研究方向、画像打分任何变体、无人值守定时抓取。

## 行为规约

- PF-01：首页与方向页分开，首页各区均有真实预览、用途和入口，不伪造个人进度。
- PF-02：方向包含具体研究对象、截止日期明确的现状、选择理由及限制；事实有来源，推荐是分析，不外传私人适配依据。
- PF-03：重要性、难度、论文类型独立；推荐深度不等于交付深度。只有摘要最多 quick，没有摘要只 entry；deep/standard 必须有相应正文依据。
- PF-04：三种深度的内容结构真实不同，类型决定章节组织；不增加空栏目或靠字数伪装精读。
- PF-05：正文/标题/操作/元数据字体明确；侧栏及主按钮不受全局链接色覆盖；长文、表格、来源、目录在桌面与手机可用。
- PF-06：技术路线不要求先选论文方向，不要求学完全部框架；资源标先修/权限/版本/核查层级，实践选学不阻塞阅读。
- PF-07：引用关系有来源，编辑关联不冒充引用。论文时间与简报整理时间分开，失败不是零新增。
- PF-08：旧公开内容去重保留覆盖级别，旧本人记录保持同源可访问；新版只读写 v3，不读写 v1/v2。迁移与删除必须另获明确授权，先导出验证。
- PF-09：private/、.grad/、密钥与私人研究材料不进入公共资源。grad-companion 用于真实内容生产，网页展示不等于网页运行技能；AI 整理不标已读。
- PF-10：CCF 期刊与会议分开，不承诺创新或录用；测试、正文审查、视觉与真实交互验收分别如实记录。

## 每日发现固定契约（/api/discover）

实现权威在 `discovery.mjs`，行为由 `tests/discovery.test.mjs`、`tests/server.test.mjs` 逐项锁定：

- 仅三个固定主题白名单 query（agent=language model tool use / rag=retrieval augmented generation / peft=parameter efficient fine tuning），无用户自由文本、不接受任意 URL；参数变体一律 400。
- 窗口=最近 7 个 UTC 日登记（from-created-date），sort=created 倒序、rows=20、select 固定字段；严格日历校验（拒绝归一化），DOI/title 必需、DOI 去重。
- 超时 12s、响应 2MiB 上限、429/无效 JSON/非法结构均为明确错误，**无种子回退、不用旧缓存冒充今日结果**；缓存 15 分钟（保留原 fetchedAt，cached=true）；全局上游间隔 ≥3s；每主题每日最多 5 次真实尝试（成败均计），超限 503 不计次。
- Crossref query 为广泛 OR 匹配，必须按「标题+清洗摘要」做两组 AND 主题后置过滤；0 条是合法结果，不称穷尽。
- 文案边界：近期登记≠近期发表；论文登记时间与简报整理时间分开；动态条目不进入内容库、不写入个人记录；仅用户点击才请求。
