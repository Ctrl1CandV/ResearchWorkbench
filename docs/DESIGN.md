## 2026-09-21 设计重构（REWORK-007，根因与裁决过程见 docs/DESIGN-REWORK-007.md）

- 阅读动线优先于功能入口：论文页顺序为 页眉 → 正文（含"下一篇"）→ "我的记录"面板 → "来源与覆盖"；精选页顺序为 当期简报 → 历史工作日索引 → 近期登记发现。位置由 render.test 断言锁定。
- 首页按每日回访价值排区：每日精选 → 论文阅读 → 方向与路线 → 技术学习 → 经典书目；更新行并列最新简报日期（时间锚点）；本人标记"在读"时论文区顶部出现直达行（PF-01 已补句）；预览卡内按钮降为普通链接。
- 记号约定：标签一律" · "连接的纯文本 meta 行（.lib-metaline/.lib-depth-note），chip 样式（.lib-badge/.lib-flag）已删除；entry 完整诚实句只在论文页页眉，列表与路线步骤用短标签"原文入口"。
- 免责分层：页脚"关于内容与来源"= 全站唯一详述层；页面级说明各页一次；卡级依据缩为一行灰字（quick/entry 不再用虚线框）。
- 装饰清理：步骤圆圈编号降为纯数字 + 连接线；技术路线标题链接与论文标题同一模式（悬停才下划线）；阶段 chip（.lib-stage-label）保留为唯一阶段锚点。
- 内容库拆分：public/content/ 六模块 + library-content.js 聚合器；服务白名单为十二个精确路径。

## 当前实现（PLAN-004/005 与每日精选工作流之后）

- 首页 #/home：五区（方向与路线、论文阅读、技术学习、每日精选、经典书目）各带用途、使用方式与真实入口；首读来自编辑设置的 typed `startHere` 材料入口，标“建议先读”，不出现任何本人进度。
- 导航为六入口：首页、方向与路线、论文阅读、技术学习、每日精选、经典书目；空 hash 进入首页。
- 每日精选页为既有扁平样式：发现区（点击才查询）→ 选编简报（“整理日期…；覆盖范围：{scope 三段式}。”一段式纯文本 + 条目列表）→ 历史工作日索引（日期列表、本期加粗、附条数与缺日说明）。**用户 2026-09-18 裁决：简报信息组织靠文本（scope 三段式，见 DAILY-BRIEF-006 §4），不引入新的视觉组件。**
- 方向页顺序：研究对象 → 当前研究情况（含 asOf 与来源）→ 选择理由 → 难点与不适用条件 → 按阶段阅读 → 可以追问的问题。
- 阅读卡按实际交付深度分四种结构：正文精读（概览/先修/章节/细读/相关文献/待核问题/自查）、正文选读、摘要级、原文入口。正文用有限 block 渲染（段落、列表、对照表、提示框、公式），不用富文本或任意 HTML。
- 字体职责：正文中英统一无衬线栈 18px/1.9；大标题可用宋体/Georgia 栈；辅助信息 13–14px。侧栏链接、主区链接、主按钮各自显式定色，不靠全局 a 覆盖。
- 技术学习为独立主干：概览分必学主干与按需深入，详情按单元给出目标、读什么、主资源（含核查层次与访问条件）、补充、自查、选做与何时跳过。

## 视觉与结构
页面以阅读为主。桌面左侧220px深墨导航，右侧冷白内容区；主导航保留方向与路线、论文阅读、技术学习、每日精选。两条 active 方向提供默认快捷入口，deferred 方向保留说明与直达链接。首页突出当前首读，而非同权重卡片网格。

## 色彩
新版变量限定body.lib。导航#15243b，书页#fbfcfd，强调#0e7663。强调色用于链接、焦点和选择，不铺成装饰背景。

## 字体与阅读
操作使用Segoe UI/Microsoft YaHei系统无衬线。论文长正文使用本地宋体栈，18px、1.9行高，最大45rem。标题和段落间距区分阅读层级。原文链接在题头直接出现，来源细节折叠保留。

## 导航和行为
路线用有先后含义的编号步骤。论文页提供目录、原文、上一篇、下一篇及返回路线。目录只滚动，不改hash。既有hash深链保持。宽屏正文与右侧辅助栏并排；1200px以下辅助内容下移；900px以下侧栏变顶部导航并单栏呈现。

## 状态与安全
可见焦点、链接悬停和文本选择使用同一强调色。动态文本用DOM文本节点。没有新增个人持久化、外部字体或后端接口。styles.css前321行旧版规则保持原样，所有新版样式限定lib作用域。
