## 2. 多智能体架构：tech-multiagent

定位：当前主技术栈；不要求先学完 T1/T2。先修是能运行 Python、理解函数/列表/字典和异常，不涉及训练、部署、K8s。主路线回答：怎样做一个受控 Agent，再让两个角色围绕同一任务交流、复核并停止；进而看懂跨工具时哪些状态不能自然共享。

贯通任务固定为“小型算术任务助手”：执行者将输入转为受限加减乘除工具调用，复核者检查结果及工具证据，必要时退回修改。练习只处理公开合成输入，工具禁止任意代码执行，不用 eval，不访问用户论文、仓库或个人记录。它是理解架构的教学例子，不是科学实验或跨 harness 性能证据。

|---|---|---|---|

### 2.1 必交教材与运行边界

唯一新文件：public/learning/multiagent-lab.md。网页只以普通链接提供阅读/下载，不解析执行代码，不新增 Python 后端；不用工作台 package.json 安装 Python 依赖。四单元通过 labPath='/learning/multiagent-lab.md'、labSection='ma-u1'…'ma-u4' 指向同一教材；labPath 仅允许这个精确值，非任意本地路径。labSection 是链接旁的章节提示，教材用相同标识作为小节标题；纯文本页面不承诺Markdown锚点跳转，下载后按目录定位。教材不计入 LIBRARY.materials 的三个起步材料。

教材必须含：

1. 适用基础、任务全貌、四阶段目录、预计操作而非承诺学习时长、Windows PowerShell 和常见终端的独立虚拟环境命令；锁定实际测试的 Python/依赖版本，说明 CPU 即可、不要求 GPU。
2. 可复制的完整代码与依赖清单，不留“自行补 model_call”或省略号。允许一个脚本分四阶段或四份完整递进脚本，但同一状态结构和同一任务贯穿。
3. 默认 mock 模式：模型替身产生固定消息，仍真实经过 LangGraph 节点、条件边、检查点和恢复；不需要密钥、不调用网络模型。说明安装依赖仍需要下载，mock 不能用来证明模型能力。
4. 可选 real 模式：选择一个官方支持的模型调用接入，完整给出依赖、环境变量、调用代码、超时与错误出口，执行者/复核者模型名分别可配；不要求两个供应商或昂贵订阅。密钥只从环境读，禁止在日志/教材中写密钥。未提供凭据时只显示运行条件，不编造真实模型结果。
5. 四阶段运行命令与预期输出；至少覆盖正常任务、非法工具、步数上限、磁盘恢复、复核退回再通过、重试耗尽、人工取消。教学记录包含阶段、输入输出、工具结果、停止原因。mock 的成本记“不适用”；真实模式 usage 缺失记“未知”，不编造 token/价格。
6. 检查点数据库和练习输出只在新建的独立练习目录中；恢复测试从检查点边界开始，明确中断节点可能重跑。用可重复的算术工具演示恢复；若演示写入，必须以请求 id 去重，不能以“用了框架”为由承诺恰好一次。
7. 末尾解释：两个角色不代表一定超过一个 Agent；本例没有跨公司 harness，不验证 Tax/Debt，也不验证结构化状态优于文档。

实施者必须在隔离目录从教材逐步执行 mock 七类检查，保存实际命令、版本、结果到实施报告；真实 API 冒烟仅在已有可用凭据且获相应调用授权时运行。没有凭据不阻塞本期离线教材验收，但报告必须写“真实 API 未运行”，不能说全部模式已测试。仅网页可打开不能通过教材验收。
