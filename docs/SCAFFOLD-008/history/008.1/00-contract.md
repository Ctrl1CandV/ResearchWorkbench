# 00 契约：目的、冻结决策、禁止项

版本：008.1。保留四目的与 6+4 选目；本修订补齐技术学习、讲解交付、导航、来源、存储和包依赖。

## 1. 用户目的（实施必须对准的结果）

顺序不分优先级；本里程碑覆盖 1、2、4，目的 3 后置。

| 目的 | 用户原意 | 本里程碑交付 |
|---|---|---|
| 1 | 把跨 harness、跨模型的多智能体**协作与通信**写进方向和路线，并引导学习（论文、博客、教程均可） | 初期只保留 **两条**方向；主方向用稀疏混媒介地图，不跟 GPT 的 12 周全表 |
| 2 | 从「找有价值的论文」进到「按什么顺序读、一篇里各部分怎么读」，用 AI 减负但不替代自己积累 | 起步地图 + 卡片三问 + 章节动作（自己精读 / 看整理 / 跳过） |
| 3 | 前端样式与编排让人能开始 | **本里程碑不做换皮**。仅为让 1/2/4 可见而过滤列表、加文本首屏；不加新视觉组件 |
| 4 | 技术宁缺毋滥，是完整可学、能用在方向上的栈 | 默认三条：多智能体架构（主）、RAG（按需）、图（浅） |

每日精选：知道相关/前沿在做什么、用了什么方法；**基本不读，不进主路线**。

## 2. 已冻结的产品决策

1. 初期探索总共 **两条**论文方向，不是三条加一。太多会不知所措。  
2. 主方向 = 跨工具（harness）的多智能体协作与通信。模型常锁在特定工具里，强且贵与弱且便宜要合作，通信往往在进程外。共享世界状态、handoff packet、wiki、检索记忆、原始轨迹都是**对照通道**，不是预设答案。  
3. 第二条 = 现有「代码智能体的修复正确性与验证」。Handoff 文献的实验场景就是 coding agent；评价素养能支撑主方向。  
4. 「动态多源可信 RAG」与「图有害融合」**撤出初期入口**（`status: deferred`）。内容库条目不删。RAG 作为技术路线保留；图作为浅技术路线保留，不再作为论文方向。  
5. 路线节点可以是论文、博客、教程、视频、技术单元，不必篇篇是论文。  
6. 路线要少。每条方向分 `startRoute`（默认展示）与 `archiveRoute`（完整谱系，初期折叠）。  
7. 用户是新生，不能审查选目。实施模型**不得**以「用户没点头」为由把 GPT 全表灌进 `startRoute`，也不得私自换成另一套几十篇清单。改选目必须新开文档版本。  
8. 不在本平台实现共享状态协议、MCP、世界状态数据库、多 Agent 编排器。那是研究方向里的候选机制，不是产品功能。  
9. 不承诺发表，不把 CCF 期刊与会议混同，不画像打分，不自动已读。  
10. 四档深度纪律不变：不能为了填 Preserve 把摘要卡写成假精读。  
11. 目的三（视觉系统设计、偏好资产换皮、390 全矩阵重做）不在本包。REWORK-007 的「文本优先、不加徽章墙」继续有效。
12. 材料节点本期只读，不增加个人记录面板，不扩展 v3；旧论文记录与导出继续可用。
13. 技术主线采用 Python + LangGraph，学习示例是下载教材中的教学代码，只在独立练习目录执行，不接入工作台运行时。提供模型替身模式与可选真实 API 模式，不要求购买昂贵模型才能学习。
14. 主方向以换手作为第一观察切片，后续包含持续分工、反馈往返和共享工件；不把研究题目冻结成中断任务接管。通道间不存在预设排名。

## 4. 与 BACKLOG 的关系

本里程碑**暂时压过** BACKLOG 第 1 项「把 SWE-bench 等补成深读卡」：不要在延后方向或非 `startRoute` 节点上扩精读。允许的内容生产只有：

- 主方向四张新 quick/standard 卡与两个博客材料；无材料可核时保留待核节点，不以 entry 占位宣称起步交付完成；  
- 代码验证 `startRoute` 已有 TOSEM standard / Agentless quick，缺的是一篇站内「怎样读实证研究」材料，不是新深读；  
- 技术三条路线的单元、已核资源及一份贯通多智能体练习教材；主方向 archive 只登记外链身份目录，不新建十张论文卡。

深读卡生产在本里程碑验收之后再按 BACKLOG 恢复。P1.5 路线差异表仍等每方向标准卡 ≥3。

## 5. 禁止项（实施时对照）

- 把 GPT 12 周清单整份写入页面。  
- 把 Structured State 或 raw trace 写成普遍胜者；Debt 的事件数、累计 token、初始长度须区分（见 07）。  
- 把 AgentPrune 写成跨 harness 问题的直接解法（它研究既定多智能体管线的通信图裁剪，未验证独立商业工具间互通）。  
- 为博客/摘要材料编造章节号、百分比、机制细节。  
- 删除 `trusted-rag` / `graph-harmful-fusion` 的数据，或删除 T1–T6。  
- 改 v1/v2、初始化 `.grad`、提交/推送（除非用户另授）。  
- 新增 chip、进度环、推荐引擎、judgment profile。  
- 目的三范围内的 CSS 结构性重做。

## 6. 核查规则（实施时补核材料与结论，不重开选题）

`startRoute` 里列出的 https 链接，入库前核查身份、所需内容与访问条件。失败时先使用同一作品的官方 HTML/PDF/作者版本；步 1 允许 02 的指定备用文章，但必须重新写与该文章一致的卡。仍失败则节点保留原序位，`availability: 'pending'`，写明失败日期和原因，移出可开始推荐，不悄悄跳到下一篇或用另一论文顶替。全部 6+4 起步节点可用才可宣称完整验收。

预印本版本以 arXiv abs 页当时版本为准，写进 `coverage.version`。

身份核查不等于结论核查：凡写 raw/notes 比较、实验设置、图号或章节动作，实施者必须读取相应原文，并在覆盖中登记定位。07 的核查记录可以指路，不能冒充本轮已经读过。技术主资源失效可按同一官方文档目录找新地址；学习目标和技术主线不变，记录迁移，不把选资源工作交给用户。
