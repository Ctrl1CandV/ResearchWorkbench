## 一句话

把平台从「三个方向 × 长论文表 × 十一条技术主干」收成：**两条起步方向、稀疏混媒介地图、读论文时知道自己读还是看整理、三条能用的技术栈**。每日精选只用来感知前沿，不进主路线。前端换皮（目的三）本里程碑不做。

## 成功标准（对用户，不是对代码）

用户打开工作台后应能：

1. 立刻看见只有两条可选方向，并知道主方向是跨工具协作、第二条是代码智能体验证。  
2. 沿主方向第一段走完约 6 个节点后，能用自己的话区分：记忆、本轮上下文、共享区、聊天消息、仓库状态。  
3. 读一篇真正的论文时，卡片告诉他讲什么、为什么现在读、哪些段自己看、哪些看整理、哪些跳过。  
4. 技术页默认只有多智能体架构（必学）、RAG（按需）、图（浅尝）；不面对 11 条课表。  
5. 不会把每日精选当成今天的作业。
6. “看整理”有可读内容；路线前后节点不会把人带回长谱系；技术主线有贯通实例和可核查的运行结果。

## 008.1 已确定的实现选择

- Python + LangGraph 为多智能体技术主线；四单元共用一个教学练习，学习者选做，实施者必须验证教学材料能用。平台只展示/下载教材，练习复制到独立目录运行。
- Explain 必须附实际讲解或可解析的正文引用；没有讲解就不显示该项。
- 首页使用带类型的 `home.startHere`；节点链接携带路线与 start/archive 上下文。短路线导航优先，旧 `paper.next` 仅作延伸阅读。
- 材料页不提供个人记录。本期不改 `notes.js`、v3 数据结构、存储键和导出格式。
- 新四篇论文与三个起步材料为必交内容；主方向 archive 的十项只用外链目录，不批量增卡。现有代码验证九步谱系保留。
- 先兼容渲染与校验，再一次性接入起步内容并切换首页入口，随后交付技术路线和文案收尾，最后验收。具体依赖和写入范围以 06 为准。
- 08 的“可实施”指契约已经可执行，不表示产品、外链、教学代码已经验收通过。
