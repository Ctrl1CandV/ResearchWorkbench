# 个人研究平台：信息架构与阅读设计

状态：规划交接稿；本轮不改应用代码、不迁移数据、不删除旧版。用户批准的三个研究方向保持不变。此文件与配套 READING-TEMPLATES-005、TECH-LEARNING-005、PLAN-004 一起构成下一轮实施依据。

## 1. 产品判断

目前页面把“先读一篇”当成整个平台的首页，缺少各部分的用途和相互关系；方向只有题目，没有帮助用户理解选择；阅读卡虽有来源，但模板与排版不能体现阅读投入的差异；技术学习过度依附论文。下一版需要解决的是这些内容组织问题，不是再换一次主题色。

平台有四个明确工作区：方向与路线帮助选题和安排阅读；论文阅读帮助理解单篇与参考文献；技术学习形成Agent研究与工程能力；每日精选负责少量新信息和历史选编。首页解释四区并给进入方式，不增加任务管理、积分、学习时长或假进度。

## 2. 页面与导航

新增首页 `#/home`，空hash进入首页。保留 `#/directions`、`#/route/<id>`、`#/papers`、`#/paper/<id>`、`#/learn`、`#/brief`，扩充现有学习详情 `#/learn/<id>`。旧链接无需迁移。侧栏增加“首页”，四区保留，方向快捷入口放可折叠分组，确保有低优先级“历史笔记”链接到 `/legacy.html`（已有入口调整名称；若实施基线已移除则恢复）。不隐藏仍未整合的数据。

### 首页

首屏必须回答“这是我的什么平台、能做什么、从哪里开始”。不用巨型标语挤掉内容。

建议标题：**研究、阅读与技术学习**。
说明：**沿研究路线读论文，补齐Agent所需技术，定期看看值得留意的新工作。**

桌面布局：
```
侧栏  | 研究、阅读与技术学习          内容更新日期
      | 方向与路线（较宽）            论文阅读
      | 三方向短说明 / 查看方向       当前首读卡 / 打开阅读卡
      | 技术学习（较宽）              每日精选
      | 必学主干 / 可选支线            最近一期 / 1–3条
      | 第一次使用：先看方向 → 打开首读 → 按需补技术
```
这里四块是四种内容的预览，不是四张同文案营销卡。每块均包含一句用途、真实条目、具体入口；移动端按方向、论文、技术、精选顺序排列。不得填充用户已读量、连续天数等未建立的状态。

首页论文推荐从编辑设置的 `startHerePaperId` 读取，标“建议先读”，不叫“继续阅读”，除非以后有本人状态依据。每日区读取最新真实brief日期，不自动显示系统今日作为更新日期。暂无新一期时仍显示历史日期。技术区展示建议起点，不假设用户基础已掌握。

### 方向列表与详情

列表每方向显示：研究对象、一个具体问题、为什么值得考虑、路线入口。第一推荐明显但不霸占整个首页。

详情顺序：方向说明 → 当前研究情况 → 为什么选择 → 难点与不适用条件 → 按阶段阅读 → 可以追问的问题。正文先讲人能理解的事情，再给论文术语。约600–1000中文字符为一方向导读参考，不是凑字数指标。

每个事实段落携带来源；“当前”必须有 `asOf` 截止日期。现有方向报告是结论输入，后续不得重排而不记录依据。私人适配理由不复制到可公开静态资产；使用用户已授权的方向结论、公开研究价值和条件化描述即可。

#### 三个方向的内容底稿（需以原报告来源逐段回查）

**代码智能体修复验证**：代码智能体能提交补丁，但测试通过不保证需求完成或没有回归。研究对象是补丁是否真的正确，以及有限时间和调用预算下应检查什么。已有传统程序修复、补丁正确性分类与代码基准研究，不能把多模型审查或多跑测试本身当创新。推荐优先探索，因为任务、输出与错误接受成本比较明确，适合从软件工程问题和可审计证据入手；这是方向选择理由，不证明用户已有设施满足研究要求。主要难点是真值、跨仓库泛化和公平预算，而不是搭更大的Agent框架。

**动态多源可信RAG**：同一事实会随时间或软件版本变化，不同来源也可能矛盾。问题不只是能否检索到相近文字，而是这些证据在目标时间是否有效、是否足以回答。已有来源冲突处理、充分性判断和时间敏感方法；增加引用、日期标签或拒答不能直接声称创新。它适合作为替代主线，因为可从公开技术文档与固定模型开展问题分析，不必先训练大模型。难点是版本真值、标注成本以及能否超过强组合基线。

**部分观测图的有害融合**：对象可能有属性、关系和多个来源；信息缺失或冲突时，融合可能比可靠单一来源更差。关注如何识别这种损害，而不是默认所有信息都应混合。已有不完整多视图、未对齐恢复和非随机缺失方法；这些与原生属性图不是同一任务。此方向作为独立方法备选，能训练图学习和问题建模能力，但需要补数学和优化基础，并落实指导条件。无标签条件下“哪个结果更正确”并非无条件可识别，必须交代假设。不得把CAMERA的机制直接说成已经验证属性图负迁移。

#### 阅读路线不是平书单
阶段标签建议为“建立问题 → 理解方法 → 看评价与反例 → 核查近期竞争”。每篇保留目的、前置、读到什么程度、下一篇；明确必读/选读与模板层级。阶段顺序与当前5篇顺序可映射，不因视觉方便重排。参考文献入口与编辑推荐分栏，真实引用必须有原文编号或来源。

## 3. 论文页视觉与文本结构

论文模板规则见 READING-TEMPLATES-005.md。不同层级改变内容结构和深度，不只是卡片变长。

### 统一排版规则
- 主阅读正文统一中文无衬线栈（Microsoft YaHei、PingFang SC、Noto Sans CJK SC、system-ui），18px桌面/17px移动，行高1.85–1.95。取消当前Georgia/Times/SimSun混排作为长正文默认；宋体只可用于克制的大标题，不混进一段正文。
- 中文标题不手动插空格或逐字加粗。h1 28–34px，h2 22–25px，h3 18–20px，辅助信息13–14px；正文约34–40个中文字符一行，字距默认，避免全局h3覆盖论文内部标题。
- 原文题名保留英文正式身份，另加编辑中文短题 `displayTitle`，不能把译名当正式论文名。英文长标题允许自然换行。
- 段落讲机制；步骤用编号列表；比较对象/条件/结论边界用小表格；一段最多突出1–2处关键短语，不整段粗体。
- 每篇开头有“这篇解决什么”和“为什么读”，但不重复lead、reasons和徽章三遍。三维分类理由收进阅读建议或来源面板，不机械列枚举。
- “作者发现”“辅助解释”“待验证问题”采用一致小标题/文本标识，不能只靠颜色区别。公式块给符号解释；未核对公式不自行重排假公式。
- 来源和未覆盖在结论附近有简短提示，完整信息可展开。quick须首屏明确仅摘要；正文选读不叫全文精读。

### 已定位的实现问题（非本轮修复）
源码核查发现body.lib a的优先级高于.lib-nav-link和.lib-btn-primary，可能把深色侧栏链接及主按钮白字覆盖成普通链接色；按钮未固定font-family，导致正文内操作继承宋体。新版必须按语义区域设置链接/按钮各状态，用浏览器计算值验证，不能继续只检查CSS包含某颜色。当前#/learn/<id>和#/brief/<id>已支持，需复用而非重建。

### 结构化内容而非随意HTML
现有paragraph字符串升级为有限block：paragraph、list、comparison、callout、formula（只有已核来源时）。paragraph内可有text/strong/em/code/link片段。全部白名单DOM渲染，禁止innerHTML/任意markdown HTML。表格保留caption及列头，手机横向滚动只限表格容器，正文不可横溢出。先用段落和列表完成内容，不为了“丰富”强迫每篇都有表格或公式。

目录由真正渲染的章节生成；页内滚动不改变路由hash。章节id用paperId+sectionId，中文标题变动不破坏锚点。原文入口、上一/下一篇在首尾可见，手机目录放正文前可折叠，不移到整篇长文末尾。

## 4. 技术学习面板

技术学习是独立主干，不是三个选题的附件。主干、研究支线、工具参考分开。详细技术选择见 TECH-LEARNING-005.md。

概览分“必学主干”与“按需深入”。每路线显示要解决的能力问题、建议先修、学习单元数量（只统计真实单元）、适用场景和入口，不显示自动完成进度。路线详情按模块逐步展开，每单元包含目标、1个主资源、最多1个补充资源、读/学什么、可选择的自查、何时跳过。学习目标服务能力而非刷完课程。

示意：
```
Agent技术学习
先建立可测试的软件与模型调用，再学习工具编排和评价。
必学主干 [软件基础] [LLM与调用] [工具与状态] ...
路线详情：概述 | 先修 | 单元目录
单元正文 | 主教程 | 自查问题 | 下一单元
按需深入：检索专项 / 训练适配 / 图方法 / 多智能体
```
无账号、计时、打卡系统；不嵌入需授权的第三方课程，不抄成熟平台的品牌与文案。

## 6. 验收场景
1. 未读任何论文的用户在首页能解释四区作用，并各进入一个真实条目。
2. 每方向能读懂研究对象、已有工作、选择理由和限制，且知道截止日期。
3. 读同一主题的导航卡/标准卡/精读卡能看到结构差异，不能只看到不同字数。
4. 无正文时推荐为精读也不得展示“精读完成”；显示待补内容与可读摘要。
5. 长英文题名、中文段落、加粗、代码、表格、来源与公式示例在桌面与手机层级稳定。
6. 不选论文方向也能进入Agent必学技术路线；旧版有用内容作为选读可找，旧笔记仍可访问。
7. 不新增假进度、假读取范围、私人静态数据、发表保证。
