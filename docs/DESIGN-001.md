# DESIGN-001 首版设计

版本：2026-09-14 / 冻结稿 v2，已补调研与预审修订，最终独立审查 pass。沿用已批准立项。

## 场景和最小范围

面向尚无方向、具备或正在补 Python 基础的新生。页面唯一主任务：比较两个入门探索入口，选择其中一个，完成一个小实验，记录本人证据和困难。不是论文推荐榜、课程平台或创新保证。推荐是 AI 策划建议，不是用户画像事实；前置能力未知要显式展示。内容先覆盖方法素养，不冒充已选定研究方向。

两条路线：优先“先判断结果是否可信”（scikit-learn 分类、训练/测试划分及评价）；备选“拆开模型的学习过程”（PyTorch 张量和自动微分）。前者适合先建立实验判断，后者适合偏机制、且有函数求导基础者。两条不构成强制顺序，每条仅一个任务。材料已由 scout 核查，详见 CONTENT-001.md v1，不使用虚构论文。

## 形态与技术

Node 24 内置 HTTP 模块启动仅绑定 127.0.0.1 的只读静态服务；原生 ES modules + HTML/CSS，无运行时第三方依赖、无构建、无云服务。node:test 验证领域状态、内容完整性、HTTP 边界。静态目录 public 是唯一白名单，不提供任意项目路径。仅接受原始 URL 精确匹配 /、/index.html、/styles.css、/app.js、/domain.js、/content.js；其他路径（含 query、编码、遍历）404，畸形百分号编码400；不做路径解码拼接或目录列表。固定资源读取前拒绝符号链接并核验 realpath 在 public 内。Host 仅允许 127.0.0.1:<实际端口>，否则403；其他方法405，HEAD无响应体。设置 CSP self（connect-src none）、nosniff、no-store、Referrer-Policy no-referrer。端口默认 4173，允许 PORT 配置；端口冲突明确报错，不杀其他进程。服务器只提供 GET/HEAD 静态资源，不接收反馈。

浏览器 localStorage 保存本工作台学习状态，明确只在当前浏览器及相同地址下恢复；非跨设备同步、非 .grad 写入。反馈不上传服务器或外部服务。无遥测、CDN、远程字体、自动外链请求。用户点击公开材料才会打开站外页面（noreferrer/noopener）。保留复制完整本地记录 JSON 文本的只读导出能力（textarea 手动复制回退）；不建设导入、自动备份、迁移或账户。

## 交互布局和视觉契约

主题：实验记录台，不是管理仪表盘。标题“先做一个小实验，再判断想走哪条路”。特色为当前任务的三段“读懂什么 / 动手验证 / 留下证据”，把知识与本人能力分开。没有伪造进度条、统计、阅读卡数、仪表盘。

色彩：冷灰纸 #F3F6FA、白 #FFFFFF、墨蓝 #172B46、蓝 #2458D3、青 #17685F、次文本 #52647B。展示标题用本地 Georgia/SimSun，正文 Segoe UI/Microsoft YaHei，代码 Cascadia Code/Consolas。字号正文至少 16px，小字至少 13px。主内容最大宽 1180px，左侧 36% 为比较路线，右侧为当前实验页；窄屏 760px 以下单列。选中路线蓝色边线和文字标识，不仅靠颜色；细线连接任务三个小节，表达实际流程，不加无意义序号。按钮、输入标签、focus-visible、错误 role=alert、保存状态 role=status；不依赖动画。主标题不占据整屏。

## 状态契约

唯一键 research-workbench:v1。schemaVersion=1，revision 为随机提交标识，focus=null|evaluation|autograd，feedback 以路线 ID 为键。每项 reading=not-started|reading|read，explaining=false|true，reproducing=false|true，evidence 字符串最多 4000 字，blocker 字符串最多 2000 字，updatedAt ISO。reading、explaining、reproducing 都是“本人自评”，完全独立，不推导认证；可撤回。初始反馈全空，不写示例进度。内容标记 editorial/AI-suggestion，source verification 为材料级事实，不属于反馈字段。

领域函数对未知版本、非对象、非法路线/枚举、类型、长度及非法嵌套值严格拒绝，不默默修复为全新记录。损坏存储时显示“无法读取原记录，已停止保存；可导出原文备份”，保留原字节并禁用保存/焦点持久化；不自动清除或覆盖。导出原始内容可用于人工恢复，不执行其中任何文本。

并发：所有修改（包括焦点）必须在同名 Web Lock 内完成读取、基线比较和写入；保存前比较当前存储原字符串和本页加载/最近成功保存时的基线，不一致拒绝写入。监听 storage 事件提示另一页发生修改，不自动覆盖本页草稿；提供“重新载入已保存记录”且确认丢弃草稿。无 Web Locks 或获取失败时停止持久化，保留草稿及草稿导出，不采用不可靠的无锁降级。加载和写入 localStorage 的异常均可见，不能声称成功。所有用户文本通过 textContent/value 呈现，禁止 innerHTML 插入。读取本身失败不是空记录，不允许覆盖且不能声称已取得原文；草稿离页提示仅尽力保护，不保证未保存草稿跨刷新恢复。

## 插件边界（v2 裁决）

采用可预览、可复制的宿主指令，绝不从浏览器猜测技能安装状态。显示“手动交接准备；本网页无法检测宿主是否安装/执行；尚未接收结果”。只有公开材料链接与任务目标进入模板，不包含本人反馈或任何私人目录。复制成功仅表示复制，不表示技能执行。clipboard 失败显示可选中文本，不伪称成功。

scout 已核验已安装 grad-companion 0.4.0 的 grad-radar：reading_record.py 是记录 CLI，不是模型服务；list/show 为只读；register/save-note 会写入且不能代标已读。身份须 arXiv/DOI/文件哈希，官方教程 URL 不能直接当论文登记。因此首版模板是“请参考 grad-companion:grad-radar 的阅读方法，解释下列官方教程的指定目标；这些是教程不是论文，不要 register/init/save-note，不读取或改写任何个人研究记录；若技能不支持教程，请明确报告不支持并仅在会话回答。公开材料：…；目标：…”。不承诺教程已进入插件阅读记录。

主协调者显式将尚未冻结的 SPEC AC-06 收敛为“手动交接准备”：验收分别记录已安装契约核验、网页生成/复制、隔离空目录 CLI list/show 真实运行；这不是阅读/发现/记录全链路接入成功。宿主模型阅读和日更发现不在本版通过项内。不会自动初始化 .grad，不调用写入脚本。
