# DESIGN-002 研究导航工作台

2026-09-14 v1 / 待独立审查。取代实验主导设计；不重新立项。

## 产品判断

主页面回答：值得研究什么、为什么适合、接下来读什么。候选不等于已验证创新。用户授权协调者择方向，旧方向只参考，不默认优先。已确认定性工程背景仅用于本会话分析，不硬编码私人画像进public。首版推荐采用可编辑画像的透明规则，不伪装实时模型推理；明确方法与限制。首屏无需先填表也有条件化候选，不假称最适合本人。

三候选问题群：Agent任务验证/工具可靠性；RAG证据与回答可靠性；小模型参数高效适配。公开内容核查后由协调者给出建议阅读顺序。推荐不是永久锁定；用户可比较、选关注、更改。Agent经历不强制锁定Agent方向。

## 核心页面

导航：研究导航 / 文献阅读 / 每日发现 / 我的研究条件。
首屏：简洁标题“把方向判断建立在读过的证据上”；当前推荐理由与待补条件，三个研究问题卡（适合条件/主要障碍/潜在贡献类型/必读论文入口），非实验任务、无伪进度仪表盘。每个方向详细区呈现：研究问题、为什么现在值得了解、方法路线比较、先读哪两篇及目的、尚须验证的新颖性缺口、CCF期刊与会议分列及目录依据。
文献阅读：六篇以上已核查论文；按方向、角色及阅读状态筛选，论文详情给身份来源、摘要级中文要点（编辑整理，非全文精读）、具体阅读问题、技术前置、推荐关联及理由。仅有证据的真实引用可标引用；其余写“推荐对照阅读”，不造引文图。选择关注/稍后读/阅读中/读过，记录本人疑问、理解与写作线索；生成卡片不自动已读。写作线索保存论文ID与本人文本，不自动生成研究结论。
画像：结构化自填工程基础（初学/熟悉Python/有LLM工程）、方法基础（未知/基础/较强）、算力（未知/CPU或API/单卡/多卡）、时间（未知/每周不足10h/10-20/20以上）、偏好（暂无/系统可靠性/检索证据/模型适配）、目标（期刊/会议/两者）。空值真实未知，禁止默认用户能力。保存前说明仅本浏览器不外传。可选正文备注仅本地。推荐规则按匹配/限制解释，不显示录用概率或伪精确百分比分。
规则：有LLM工程对agent和rag有基础匹配；检索偏好提高rag、系统偏好提高agent；模型适配需较强方法基础且单卡以上，否则明显提示门槛；低时间所有候选提示先小范围文献核查；未知算力不臆测自筹。排序平分维持编辑阅读顺序，不叫最佳方向。用户选关注独立于排序，画像变化不默改关注。

## 内容冻结补充

公开内容与首读自查标准见CONTENT-002 v1：每篇明确必学前置、三项理解标准、理解不足/达到标准的下一步，不要求入门实验。默认agent/rag/peft为编辑阅读顺序，非用户旧主线默认、非已证明新颖性。所有论文摘要覆盖明确，未全文核验具体章节号不硬写。

## 每日发现

以下以CONTENT-002的“每日发现固定契约”为最终接口裁决，覆盖下段尚未确定的API与发布时间措辞：实际来源Crossref，最近7个UTC日登记（非发表），published只保留原精度展示，缓存保留原fetchedAt；不自动降级、不伪称预印本覆盖。动态条目只读摘要与外链，未进入精读笔记库。额外参数拒绝，限额/无效日期/无摘要/零结果均有明确测试。

必须真实拉取而非固定种子冒充今日内容。仅用户点击“获取近期论文”发请求（本次不创建定时自动化），最近7天公开主题检索，显示检索时间、论文发布时间、覆盖主题/来源、摘要有无、错误/无结果。API方案在公开调研后冻结。客户端只发送三个允许主题ID及明确用户触发；后端固定公开HTTPS源、禁止任意URL/自由文本，不含个人画像与笔记。服务绑定127.0.0.1且Host校验，GET /api/discover?topic=<allowlist>。固定超时12s、响应2MB上限、20条上限、每主题缓存15min、并发复用，返回来源与fetchedAt及windowStart。失败不能用种子冒充结果。每日发现条目以真实标题/日期/摘要原文展示，标注来源摘要未全文阅读；无在线模型时不伪装自动中文深读，可用已核验种子的中文导读补充。网络查询公开词，界面点击前解释。

## 技能复用

grad-companion:grad-radar已有阅读协议/用户已读边界继续复用，详情提供仅含公开论文URL+阅读问题的宿主指令预览复制；手动触发，网页不自动执行、不读写.grad、不传本人备注。论文身份为arxiv/DOI，不以标题注册。每日公开检索不冒充插件每日发现全流程。已核查安装脚本的list/show可用，不能据此称宿主模型执行。

## 状态和安全

新键research-workbench:v2，旧v1原文不读取迁移或删除。schemaVersion2、revision、profile、focus（null/agent/rag/peft）、paperNotes（按已知paperId：status unread/queued/reading/read、question/understanding/writing各最多4000字）。初始本人数据空。严格schema验证，未知版本/非法枚举停写留原文；localStorage读失败不当空。所有写入Web Locks串行+原字符串比较；缺锁停写但浏览/草稿可用，错误不清草稿；保存中禁止导航丢稿/重载，编辑后留dirty。切换有草稿先确认放弃，取消不变；确认重置。导出原文和草稿清晰分开，串行复制或手动文本备份。所有文本textContent，外链https allowlisted论文源/noopener noreferrer。

静态服务复用显式资源白名单、真实路径防越界、符号链接拒绝、Host限定、no-store、nosniff、CSP。新API仅公开源，浏览器connect-src self以允许同源API；不接收个人内容或任意请求代理，无CORS。服务密钥/个人记录无访问接口。依赖优先Node内置，不装巨型框架。

## 测试与验收

真实研究流：条件可编辑保存恢复→推荐解释随条件变化→打开论文→看到筛选依据/阅读问题/对照关系→保存疑问和写作线索→刷新恢复且已读不自动变化→真实近期发现或明确外部失败。目录期刊会议分开，来源覆盖明显。自动测试schema、推荐规则、两论文隔离、损坏/并发保护、API白名单/超时/响应超限/日期/空结果/错误、UI标签。真实浏览器核心流程与390px截图、错误/恢复；不把源码正则当交互证明。个人研究选题创新性尚未系统证伪，不能宣称已经确定能发表的课题。
