# 结构化阅读提取：The Rise and Potential of Large Language Model Based Agents

## 作者组织路线

1. §1 用 World Scope 五层（语料、互联网、感知、具身、社会）说明：纯 LLM 停在互联网文本层；Agent 要靠拓宽感知/行动、再组成社会才可能往上走。
2. §2 从哲学/AI 定义 Agent，用简史对照符号、反应式、强化学习，再用自主、反应、主动、社会能力解释 LLM 适合当控制器。
3. §3 给出可裁剪的 Brain–Perception–Action 循环。Brain 含语言、知识、记忆、规划、迁移；Perception 从文本扩到视听及其他；Action 为文本、工具、具身。
4. §4 按单 Agent（任务/创新/生存）、多 Agent（无序/有序合作与对抗）、人机（指令—执行者 / 对等伙伴）写实践。
5. §5 从个体/群体行为与“人格”，到文本/沙盒/物理环境，再到开放—持续—情境—有组织的社会模拟及风险。
6. §6–§7 评测四维（效用、社会性、价值观、持续演化）、对抗/可信/误用、规模化、AGI 路线与 AaaS；结论按前述顺序收束。

## 压缩原则

- 保留分类依据、机制取舍、失败模式和作者自己划的边界。
- 压缩代表系统长名单、编码器/语音工具清单、教育医疗商务应用枚举，以及失业/科幻类比中的叙事铺陈。
- 被引系统一律标为综述转述。
