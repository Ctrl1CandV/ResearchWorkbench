## 1. 分层范围（为什么不是百科无限扩张）

- **背景层**（路径 A）：AI 基础发展的六条线索——符号与搜索、统计学习、深度学习、注意力/Transformer、预训练与基础模型、对齐与指令。它们不是 Agent 的直接研究对象，但 Agent 的每个部件都站在这些线索的末端。背景层只讲「问题动机与核心思想」，不展开技术细节。
- **Agent 主体层**（路径 B–E）：按 Agent 的组成组织——总览与闭环、感知与多模态、推理与规划、行动与工具、知识检索、记忆与状态、多体协作、学习适应、可靠性与安全、评测与成本。这是本包的主体。
- **深入专题**（路径 D/E/F 中的指引节点）：记忆与通信已有专门的已核来源包（既有审计：2 篇有正文综述 + 4 篇近邻详读），本包只做接入口，不重复其内容。
- **明确的缺口**：可靠性安全、学习适应、感知多模态在本包内只有框架级或摘要级来源，相关节点按此强度写，并已登记「下一轮候选」（§5.3）。

## 3. 关系类型与读法声明（先于正文阅读）

节点与路径之间的关系只使用以下五种语义，**不得混用**：

1. **【历史发展】**：方法在时间上的先后与思想更替（如符号主义到统计学习）。历史先后不等于后者全面优于前者，多条主线是**并行分支**（符号 vs 统计、预训练 vs 强化学习、RAG vs 长上下文），不是单线进化。
2. **【方法依赖】**：后一节点的方法建立在前一节点能力之上（如基础模型依赖 Transformer）。
3. **【组成】**：同一 Agent 系统的部件关系（感知、记忆、规划、行动互为组成）。
4. **【应用】**：方法落到场景（应用不反向证明方法普适）。
5. **【编辑学习顺序】**：本包建议的阅读/学习次序，是**编辑选择**，不是引用关系，更不是必然演化规律；任何路径都可以跳读。

日期纪律：节点中的时间只给到「有公开证据的粒度」（论文版本年份、广为人知的历史时期），不虚构精确时间线；本包讲述的不是单一来源的 AI 通史，而是多条并行线索在 Agent 处的合流。

## 4. 学习路径与节点正文（供直接学习；原文为证据与选读）

### 路径 A · AI 基础发展（背景层）

**引导段**：这一层回答「Agent 的零件各自从哪来」。六个节点对应六条线索，每条约 5–10 分钟即可建立轮廓。读完后你会知道：为什么今天谈 Agent 离不开 Transformer，为什么「模型变大」之后还要专门谈「对齐」。不必记住任何年代，记住每条线索**解决了什么旧问题、带来了什么新限制**即可。

**术语**：符号系统（用符号+规则表示与推理知识的人工智能路线）；连接主义（用人工神经元网络学习表示的路线）；偏差-方差权衡（模型简单到欠拟合与复杂到过拟合之间的 fundamental 张力）；自监督学习（从数据自身构造监督信号，如「猜下一个词」）；RLHF（用人类偏好训练奖励模型，再以强化学习优化语言模型）。

**A1 符号与搜索**【历史发展】来源：bg-neursym（摘要级）
问题动机：机器能否「思考」？早期 AI 的答案是先把知识和推理规则显式写下来。核心思想：智能可用符号表示 + 逻辑规则 + 搜索实现；定理证明、专家系统、经典规划是其代表，面对组合爆炸时靠启发式裁剪搜索空间。具体例子：逻辑定理证明器、医学诊断专家系统、靠大规模搜索与评估函数取胜的象棋程序。能力变化与局限：在规则封闭的窄域达到高水平，但遭遇知识获取瓶颈——常识写不完，环境一变就脆弱。前后关系：这条线索没有死亡，它与统计学习是**并行分支**；bg-neursym 综述的意义正在于系统梳理「神经 + 符号」两系如何互相借鉴（神经符号计算），是理解后来「让语言模型调用形式化工具」的思想前史。

**A2 统计学习**【历史发展】【方法依赖】来源：bg-deepnat（摘要+元数据级，其背景脉络属领域共识）；备选 bg-dom-cacm
问题动机：知识手写不完，能否从数据中自动归纳规律？核心思想：学习 = 从有限样本逼近未知函数；训练/测试划分、泛化误差、偏差-方差权衡、过拟合与正则化是通用语言；监督与无监督是两类基本设定。具体例子：垃圾邮件分类、支持向量机与集成方法时代的表格数据建模。能力变化与局限：表现高度依赖人工特征与数据质量——这个瓶颈是 A3 的推动因素之一（并非唯一动因，算力与数据条件同样关键）。前后关系：它给深度学习提供了问题表述与评测习惯；bg-dom-cacm（备选）用三页纸把这层常识讲得非常清楚，适合先读。

**A3 深度学习**【方法依赖】来源：bg-deepnat（Nature 2015 正式版，摘要级）
问题动机：特征工程人工昂贵、领域迁移差。核心思想：多层可微函数 + 反向传播，让机器自动学「表示」：底层抓边缘纹理，高层抓物体语义；卷积网络处理空间结构，循环网络处理序列。具体例子：视觉识别与语音识别在 2010 年代前半的跃进（该综述的历史脉络）。能力变化与局限：数据与算力饥渴、决策可解释性差、对分布外输入脆弱——这三条限制一路带进 Agent 时代。前后关系：方法上它仍是统计学习（经验风险最小化），依赖 A2 的框架；与符号线索并行不悖。来源备注：bg-deepnat 是三人署名的 Nature 教程综述，权威但已十年，细节以近年的文献为准。

**A4 注意力与 Transformer**【方法依赖】【组成】来源：bg-efftrans（摘要级；原始 Transformer 论文为背景常识，未入本包核验）
问题动机：循环网络逐步处理序列，难并行、长程信息易衰减。核心思想：自注意力让序列中任意两对位置直接交互（查询-键-值、缩放点积、多头），加位置编码保留次序，整个架构高度可并行。具体例子：机器翻译质量跃升是原始论文（2017，NeurIPS）的标志性结果。能力变化与局限：标准注意力的计算与显存随序列长度**平方增长**，长文本与多轮交互场景被卡成本——bg-efftrans 综述的主题正是这条效率谱系（稀疏/线性/近似注意力等）。前后关系：它是 A5 基础模型的主要现实底座（同期也存在卷积等其他路线，Transformer 最终成为主流），也是 Agent 长上下文问题的技术根源。

**A5 预训练与基础模型**【方法依赖】来源：bg-fm（v3 2022，摘要级）
问题动机：每个任务单独训练一个模型太浪费，能否「一次训练、到处适配」？核心思想：在大规模语料上做自监督预训练（如语言建模），再通过微调或提示适配下游任务；该报告还提出：规模到达一定程度后出现「涌现」能力——**这是报告的论点，且「涌现」在后续文献中有争议**（有工作认为所谓突变部分是评测指标不连续造成的假象，能力提升实则平滑），本包引用时按「报告的提法」对待，不当作已裁决事实。具体例子：该报告点名的 BERT、GPT-3、DALL·E 一代模型。能力变化与局限：报告的主旨是机会与风险并陈——能力涌现但不可靠，评估与治理滞后，能力集中于少数机构。前后关系：方法依赖 A4；它与强化学习（A6 及推理模型的训练路线）是**并行分支**在 Agent 处合流。备注：这是斯坦福 CRFM 的百余人研究报告，不是同行评审论文，引用其判断时注明「报告的论点」。

**A6 对齐与指令跟随**【方法依赖】来源：bg-instructgpt（NeurIPS 2022，摘要级）
问题动机：模型变大不等于听用户话——会跑题、会产生有害或不诚实内容。核心思想：先指令微调，再用人类反馈强化学习（RLHF）：人类比较答案训练奖励模型，以 PPO 优化语言模型对齐人类偏好；后续的宪法 AI / RLAIF 是用 AI 反馈替代部分人类标注的并行分支。具体例子：论文摘要自陈 InstructGPT（1.3B 参数）在人类偏好比较中胜过 175B 的 GPT-3——规模之外还有「听不听话」的维度。能力变化与局限：奖励黑客、偏好因人而异、对齐可能损失部分能力（对齐税）。前后关系：依赖 A5；它是 Agent 时代工具调用（D1）与角色扮演（B1）可靠性的总前提。

### 路径 B · Agent 总览：从一次问答到闭环系统

**引导段**：路径 A 的每一篇都在讲「一个模型」；从这一层开始讲「一个系统」。两个节点建立 Agent 的总体图景与它和普通聊天机器人的本质差别，是后面所有专题节点的坐标系。

**术语**：Agent（感知环境、自主决策、行动并持续运行的计算实体）；闭环（行动结果反馈回决策的循环）；接地 grounding（结论由外部环境验证而非模型自洽生成）。

**B1 Agent 与「感知—规划—行动」循环**【组成】来源：agent-llmagents（§1–§2 框架级已核）
问题动机：一次性问答完成不了多步真实任务（查资料、填表、改代码）。核心思想：把语言模型放进闭环：接收环境/用户输入 → 更新记忆 → 规划下一步 → 行动 → 观察结果，循环到目标达成。agent-llmagents 以四模块组织这一构造——profiling（角色与画像）、memory（记忆）、planning（规划）、action（行动）（§2.1，目录级已核）。具体例子：「AI 助手订机票」的教科书式循环：查班次→比价→下单→确认。能力变化与局限：框架各模块的实现差异极大，「用了某框架」不等于解决了任何机制问题。前后关系：本层是 C/D/E 全部专题节点的容器。

**B2 Agent 与一次问答的本质差别**【组成】【应用】来源：agent-llmagents（§1 摘要级）
问题动机：只是「包一层循环」，差别真的大吗？核心思想：差别在三处——多步交互带来**状态累积**（上下文就是状态）、**误差累积**（每一步的小错沿链放大）、以及**环境接地**（行动成败由真实环境裁定，模型无法靠流畅自洽蒙混）。具体例子：多轮任务中第二步误读了第一步的订单号，后面全链崩溃——单轮问答里这种错误无从发生。能力变化与局限：任务越长线，规划与记忆的短板越暴露，这正是 C3/D3/E2 要展开的问题。前后关系：B1 的推论节点，说明为什么 Agent 的研究议程几乎等于「让循环在长任务上不衰减」。

### 路径 C · 感知与认知核心

**引导段**：Agent 的输入侧（感知）与「想清楚」（推理、规划）。这一层三个节点对应三个专题综述来源，是本包中「专题综述」密度最高的一层，适合在读完路径 B 后按顺序或按需跳读。

**术语**：自注意力（见 A4）；CoT 链式思考（要求模型先输出中间推理步骤再给答案的提示范式）；重规划（根据执行反馈修正后续计划）。

**C1 感知与多模态**【组成】来源：agent-mm（摘要级；venue 为作者自注）
问题动机：世界不只是文本——图像、音频、视频怎么进语言模型？核心思想：以语言模型为「大脑」，用视觉/音频编码器把原始信号对齐到语言空间，统一用指令跟随接口调度多模态任务。具体例子：该综述摘要点名的看图写故事、免 OCR 的数学题推理。能力变化与局限：幻觉从文字扩展到感知（「看见」不存在的东西）、细粒度与空间理解仍弱——感知错误会作为 B2 误差累积的第一环进入闭环。前后关系：组成 B1 的输入侧。备注：NSR 接收仅 abs 评论字段自注，本轮未检到正式版记录，按「已接收待刊」对待。

**C2 推理：链式思考与推理增强**【方法依赖】来源：agent-reasoning（Findings of ACL 2023，摘要级）
问题动机：参数记忆「背」不出多步算术、多跳逻辑——答案需要在推理过程中逐步算出。核心思想：让模型生成中间推理步骤再作答的 CoT 范式，配合多采样取一致、检索外部知识辅助、训练侧推理数据增强等路线；该综述系统梳理了当时（2022–2023）的推理增强方法谱系。具体例子：多步算术与常识推理任务上，「先推理后作答」显著优于直接作答。能力变化与局限：步骤变长不等于结论变对，自我纠错不可靠，且无形式保证。前后关系：依赖 A5 的规模能力，是 C3 规划的认知基础。备注：该文写于 2022–2023，此后推理模型（RL 训练专门化）是快速演化的并行分支，本包不展开。

**C3 规划与任务分解**【组成】【方法依赖】来源：agent-llmagents（§2.1.3 框架级已核）；agent-reasoning（背景）
问题动机：长任务无法一次想出全部步骤，且环境会中途变化。核心思想：分解—执行—观察—重规划的闭环；agent-llmagents 把规划模块明确分为**无反馈规划**与**有反馈规划**两类（§2.1.3，目录级已核），后者把执行结果重新纳入决策。具体例子：旅行规划需先分解为订交通/住宿的子任务，执行中航班取消则触发重规划。能力变化与局限：计划漂移（执行偏离原计划后模型不自知）、子目标分解谬误、重规划的成本随任务长度上升。前后关系：组成 B1 的决策中枢，依赖 C2 的单步推理质量。

### 路径 D · 外部能力扩展：工具、检索与记忆

**引导段**：模型自身的参数是「死知识」，这一层讲 Agent 向外的三只手——调用工具（D1）、检索知识（D2）、读写记忆（D3）。三个节点对应三篇已核综述，也是与本工作区主方向（共享状态、表示组合、计费）咬合最紧的一层。

**术语**：工具学习（模型选择并调用外部 API/程序完成自身不能做的事）；RAG 检索增强生成（生成前检索外部知识注入上下文）；记忆操作（记忆的写入/管理/读取，见 D3 引用的四问框架）。

**D1 行动与工具使用**【组成】来源：agent-tools（ACM Computing Surveys 2024，框架级已核）
问题动机：模型不知道实时信息，也不能真正执行操作。核心思想：把 API、搜索引擎、代码解释器当作模型的「外骨骼」；工具学习要回答四个子问题——工具集里有什么、何时用、参数怎么填、结果如何并回回答。agent-tools 以组件连接与「从意图到计划」的流程组织方法（§3.1–3.2，目录级已核），并覆盖从示范与反馈中学习工具使用（§3.3）及安全可信工具学习专节（§5.1）。具体例子：数学题调计算器、查实时天气、代码解释器跑数据分析。能力变化与局限：选错工具或填错参数的误差会级联放大；权限与安全授权是开放问题。前后关系：组成 B1 的输出侧，可靠性总前提来自 A6。

**D2 知识检索与 RAG**【组成】来源：agent-rag（预印本 v5，框架级已核）
问题动机：幻觉、知识过时、结论不可溯源。核心思想：生成之前先检索外部知识库，把检索结果注入上下文共同生成；该综述把范式演进整理为 Naive → Advanced → Modular 三代（§II，目录级已核），并按检索（数据源/索引/查询优化/嵌入）、生成（上下文整理/微调）、增强过程（迭代/递归/自适应检索）三组件展开（§III–V）。具体例子：带引用出处的开放域问答。能力变化与局限：检索质量决定上限、注入上下文稀释注意力、模型可能「引用但不理解」。前后关系：与「长上下文」是**并行竞争又互补**的两条路线（该综述 §VII-A 专节），与 D1 工具谱系交叠（搜索即工具）。备注：预印本（评论「Ongoing Work」），分类术语已被社区广泛采用，但引用其具体图表前需补读原文。

**D3 记忆与状态（概述级，深入见既有审计）**【组成】来源：survey-mem-tois（TOIS 2025，CCF-A；既有审计 §1）
问题动机：上下文窗口有限且昂贵，跨会话的经验与事实会丢。核心思想：用四问组织记忆研究——**来源**（单次任务内/跨任务经验/外部知识）、**形式**（文本或参数）、**操作**（写入/管理/读取）、**评测**。具体例子：MemGPT 把记忆分主上下文与外部存储、由控制流函数自主搬运（站内卡已核）。能力变化与局限：该综述在其写作时点（2024 年 4 月版）判断「尚无面向记忆模块本身的开源基准」——**这是时点判断**，此后 LoCoMo、LongMemEval、MemBench 等基准已出现，引用必须带时点限定（既有审计 §7 已记录）。前后关系：组成 B1 的状态侧，也是本工作区主方向的核心变量（表示选择直接决定记忆/交接的质量与成本）。**深入专题（共享记忆、多智能体记忆、通信内容分类）不重复展开，直接读既有审计。**

### 路径 E · 群体、评测与可信

**引导段**：单个 Agent 之上与之外的问题：多个 Agent 如何协作（E1）、怎么度量好坏与代价（E2）、出错与安全怎么办（E3）、部署后如何继续学习（E4）。这一层是「系统观」的收束，也最直接地通向本工作区的研究方向。

**术语**：多智能体系统（多个 Agent 分工/协商/协作完成任务的系统）；基准 benchmark（固定任务集合上的标准化评测）；提示注入（恶意构造的输入诱导模型/Agent 违背原意图）；持续学习（部署后持续吸收新经验而不灾难性遗忘旧能力）。

**E1 多智能体协作**【组成】【应用】来源：agent-llmagents（§3 框架级已核）；survey-comms-fcs（既有审计，CCF-B）
问题动机：单个 Agent 的角色视角与能力边界有限；复杂任务天然分工。核心思想：为不同 Agent 设定不同 profile（角色、技能），通过通信协调完成共同任务；agent-llmagents 把应用按社会科学、自然科学、工程三类组织（§3，目录级已核）。具体例子：模拟软件团队的多角色开发（需求/编码/测试 Agent 分工）。能力变化与局限：通信 token 成本、一个 Agent 的错误沿通信传播、出错后责任难归属。**通信本身是一等问题**：协议、范式、显式/隐式内容分类见既有审计 survey-comms-fcs（通信中心综述，框架级正文已核）。前后关系：B1 的群体推广；多 Agent 之间的状态共享与交接表示正是主方向的研究对象。

**E2 评测与成本**【应用】来源：agent-llmagents（§4 框架级已核）；bench-agentbench（备选，身份已核）；bg-efftrans（成本侧）
问题动机：「能跑通」不等于「好」，且成本常被完成率掩盖。核心思想：评测分主观（人类偏好）与客观（任务指标）两路（agent-llmagents §4，目录级已核）；基准走向多维化——备选的 AgentBench 以 8 个环境评推理与决策（abs 评论自注 ICLR 2024）；成本侧，注意力随长度平方增长（bg-efftrans）使长上下文 Agent 的 token 账单成为一等指标。具体例子：站内既有审计的近邻详读「Compression Cost」用实验证明——任务完成率不变的压缩，运行中的再获取交互成本可能翻数倍，**完成率看不见这笔账**（该结论属既有审计，本包不重复转述细节）。能力变化与局限：基准污染、过程指标缺失、不同基准的设置不可比。前后关系：应用维度贯穿所有节点；「质量与成本分列记账」正是本工作区主方向的计费轴。

**E3 可靠性与安全（框架级，专源待补）**【组成】来源：agent-llmagents（框架级）；agent-tools（§5.1 专节标题已核）
问题动机：幻觉、提示注入、越权操作会沿 D1 的工具进入真实环境——Agent 的风险面比聊天机器人大。核心思想（框架级）：该总览综述将可靠性作为 Agent 落地的核心关切组织讨论；agent-tools 设有「安全可信工具学习」专节（§5.1，目录级已核），指向权限控制、恶意输入防御等子问题。具体例子：恶意网页内容诱导 Agent 泄露会话数据（提示注入，背景常识）。能力变化与局限：**本轮未选入专门的安全/对齐综述**，本节点只作框架级导引，任何「安全机制有效」的结论性表述在补核专源前不得出现在导读中。前后关系：依赖 A6 对齐与 D1 工具授权设计。

**E4 学习适应（框架级，专源待补）**【组成】来源：agent-llmagents（§2.2 框架级已核）
问题动机：部署后模型权重冻结，新经验从哪来？核心思想（框架级）：三条互补路线——上下文内学习（提示与记忆写入，最快但随上下文受限）、参数更新（微调/持续学习，彻底但有灾难性遗忘）、工具与流程固化（把经验沉淀为可复用外部资产）；agent-llmagents 按**是否微调**组织能力获取（§2.2，目录级已核）。具体例子：D3 的记忆写入即第一条路线；站内既有审计的「Grounding Agent Memory」条目提示——未经核验的经验写入会把错误一并固化（其条目为摘要级，见既有审计）。能力变化与局限：经验质量参差、写入什么/何时写是策略问题。**本轮未选入持续学习/自进化专源**，按框架级对待。

**E5 代码智能体与软件工程应用**【应用】来源：agent-llmagents（§3 工程类应用，框架级已核）；站内 SWE-bench 卡（本工作区已核条目）
问题动机：软件工程任务步骤长，但有一个开放域少有的优势——验证信号便宜而可靠（测试通过与否）。核心思想：把「读 issue → 定位代码 → 修改 → 跑测试」的循环交给 Agent；agent-llmagents 将此类归入工程应用（§3，目录级已核）。具体例子：站内 SWE-bench 卡记录的基准——从真实 GitHub issue 出发修复 bug，以测试通过为判据（该卡为本工作区已核条目，详细导读在站内）。能力变化与局限：长程任务中的错误累积与「修一个坏一个」的回归问题突出，正是 B2 误差累积在工程域的具体化。前后关系：通向本工作区第二条起步方向 code-agent-verification；与 E2 的评测问题天然耦合（测试即客观指标）。

### 路径 F · 回到本工作区的研究方向

**引导段**：最后一层是「编辑学习顺序」的落点：把全景映射回 cross-harness-collab 主方向，告诉你每条线索在主方向的哪个位置变成真问题。读完路径 A–E 后再读本节点；反过来，主方向的阅读卡住时，也可以按本节点的映射回到对应背景节点补课。

**术语**：handoff 任务接续（一个 Agent 把未完成任务连同状态交给另一个 Agent）；表示组合（传递与保存任务状态时选用的信息表示方式及其组合）。

**F1 从全景回到主方向：协作机制 × 表示组合 × 计费**【编辑学习顺序】【应用】来源：本包节点映射 + 既有审计
全景层中，主方向直接动用的节点是：E1（多体协作与通信）、D3/D2（状态与知识的表示选择）、E2（计费与评测）、C3（规划在交接中的连续性）。对应关系：通信成本与冗余（E1）→ 预算约束的动机；记忆形式与操作（D3）→「状态保存在哪里、保存什么语义」；检索与工具（D1/D2）→「如何获取」的手段谱系；完成率之外的交互成本（E2）→「如何计费」的账本结构。**下一步深读**：既有审计的 2 篇有正文综述（survey-mem-tois 记忆机制、survey-comms-fcs 通信中心，均已核正文）+ 4 篇近邻详读（Compression Cost / Do Not Restart / MemCollab / Routed Graph Handoff）是主方向的第一批精读材料；本包不重复其内容。注意：本节点是编辑映射，不是引用关系；主方向的四轴框架是用户讨论形成的编辑分析框架，不是综述公认分类（既有口径，不在这里改判）。

## 5. 使用说明与如实限制

### 5.1 正文与原文的关系

| 层 | 内容 | 粗略量级 |
