## 3. 推荐的内容产物

```text
docs/research/surveys/<survey-id>/
  selection.md          # 选文、互补候选和元数据核验
  source-manifest.json  # 版本、原文结构、定位和处理状态
  extraction.md         # 逐节转述式提取，不复制整篇原文
  reading.json          # 原创讲解，public 数据的权威输入
  review.md             # 来源检查、试读、缺口与修改

private/surveys/<work-id>/<version>/
  ...                   # 必要的本地派生解析/图像；不提交，原 PDF 仍留用户原目录
```

首期不建两套正文权威：reading.json 是审查对象，public 模块由转换脚本确定性生成，禁止两处分别手写。若改选更合适的单一数据源，在 B 写明编辑/生成方向，并保证后续只改一处。转换只作用于明确 surveys 导出区域，不重排旧论文库。

语法/引用校验不能认证解释正确或原文读全。敏感请求与个人数据移入 private，只发布一般化主题和公开来源。原论文长篇原文不进入 public/docs。

## 4. 验收用具体任务

### 内容与检索

- 输入宽领域：有实际查询、合理范围和少量有理由的推荐；新而低引用的综述不会被全部排除。
- 输入既有综述：确认版本后直接生产；正式版和预印本去重，不混章节。
- 逐节清点首篇：分类、评测、局限、关键图表均实际读取；检索 top-k 片段不能代替全文。
- 三种样稿能回答 02 的试读问题；转述被引研究不伪装逐篇查过原文。
- 测试只有摘要、缺正文节、图注可读但图不可读三种情况：显示缺口，不能标完整。
- API 失败或引用数缺失时如实处理，不编结果。

### 页面效果

- 1280/1440 桌面实看书架、概览、长文、比较表；正文不被图挤占，节点和连线可辨。
- 真点击展开组→选单元→正文→原文→返回；回到同文章/分支；前进、后退、刷新深链有效。
- 键盘可达节点、目录和下一节；焦点可见，不只靠颜色或 hover 传达信息。
- 用真实复杂文章结构检查布局；可另加明确标记的合成压力数据测长标题、多子节、交叉边，不能混入正式书架。
- 正文连续常显，来源不抢阅读空间，论文年份及影响理解的缺口仍可查。

### 回归与记录

- `npm test`、新增针对性结构/路由测试、`git diff --check`；不照抄以前的测试数量。
- 旧 `#/map?node=land-d3`、综述论文页、方向链接仍可用；未知新 ID 返回说明及书架入口。
- notes v3 与 guidance 数据在隔离测试中逐字节不变；新增 surveys 不被旧 computeEffective 丢失/错误覆盖。
- server 只允许必要静态文件；不开放 docs/private/.grad，不添加任意 URL 抓取或写接口。
- 生成内容通过安全 block 渲染；HTML、javascript URL 等输入不执行。
- 内容核查、截图、交互、自动测试分别记录；浏览器受阻如实列未执行，不能以 DOM 字段数宣布视觉通过。
