## 后续执行顺序

### A：完成来源与真实内容样板

- 从用户已有三篇 PDF 中推进；首篇继续做纵向闭环。读取完整正文与必要附录，逐项核对图表、分类、关键比较、限制和代表文献范围。
- 固定 PDF 版本和内容 hash；在来源清单中区分文本可提取、章节已阅读、图表已看、讲解已核验。目录每项都映射到阅读单元或明确的参考/缺项处置。
- 继续扩写首篇，保留当前三个单元 ID；章节组织按文章本身的逻辑决定。章节材料支持到哪里，正文写到哪里；分类、机制、比较使用适合它们的写法。
- 由独立只读审查者试读样稿并对照原 PDF，修正具体遗漏或推断。内容样稿审查通过后扩展生产。

### B：固定数据和生产方式

- 按 03 定义可判别的 block 类型、结构化证据、版本、节到单元映射、阅读路径和关系来源；给出非法输入与缺口的处理。
- 当前 public 模块是唯一正文编辑位置。迁移时将阅读稿确定为单一权威输入并生成 public 发布数据；避免两份正文各自修改。
- 候选可以只有来源与范围；partial/complete 状态按照实际来源与单元核查结果校验。校验要阻止缺核心内容仍标完整、引用断裂、比较来源混淆和无依据关系。
- 将书目按论文身份去重，接到现有论文库；准确版本的节页定位另存，保持旧论文 ID 与本人记录兼容。

### C：完成一篇真实阅读闭环

- 文章内结构图、作者目录和正文使用同一份阅读数据；作者分类、语义关联与编辑读序在图上各有说明。
- 实现章节分组/局部展开、选中关系、图到正文、上下单元、来源定位及返回同分支；保留可读文字目录。
- 来源入口按固定版本处理。本地 PDF 的文件名与物理页可回查；需要实现可点击原文时，应限定准确来源，不开放任意本机文件路径。
- 实际走查 1280/1440 的长文、图、比较表、键盘、返回/前进、刷新深链，以及旧地图和个人记录兼容。

### D：完成第二篇与可重复流程

- 用 FCS 2024 综述验证第二次全文生产。三篇现有 PDF 都保留准确状态；第三篇可在同一流程成熟后接入。
- 网站提供领域/关键词/指定文章请求，能复制任务或导出请求给 Agent。原文→来源清点→阅读稿→审查→校验→发布的流程写成可复用说明与样例。
- 本轮用户指定本地来源，实际验收先走指定文章路径；领域检索的任务与筛选规范可以落地，外部选文仍按用户后续需求执行。

### E/F：文章关系与最终验收

- 已有两篇完成材料后，按真实覆盖/互补范围制作文章间入口和可解释的关系；支持进入各自内部结构与正文。
- 文章间图原属后续积累阶段，可在 D 后推进。关系必须有两端依据；独立文章允许没有连线。
- 汇总内容审查、结构校验、实页交互与回归，逐项更新实施报告。测试通过不能代替内容或图文效果验收。

## 整体完成标准

至少一篇经完整来源与内容复核的阅读包能从书架走到内部图、充分正文和原文位置；第二篇验证同一生产流程可以复用；请求交给 Agent 的流程可用；未来文章关系的数据和入口能够接入实际材料。三篇状态真实，正文保留充分解释、比较、例子与限制。完成这些门槛后再报告整体完成。
