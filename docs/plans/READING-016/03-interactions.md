# 交互、状态与兼容契约

版本：v1.2 · 2026-10-05。A1 增补综述主页侧栏及原生 DOM 集合约束；前轮路由、来源和个人记录契约继续有效。

## 1. 状态分层

| 状态 | 存放位置 | 生命周期 |
|---|---|---|
| 综述主选择 | 既有 `research-workbench:survey-shelf:selected`，读写保留 try/catch | 合法值沿用，坏值回退真实文章；不可用时退为内存 |
| 综述搜索、目录滚动、每篇的关联对象、关联搜索 | `surveys.js` 模块内存 | 栏目往返保留，整页刷新清空；刷新仅恢复合法主选择 |
| 任务输入、类型、展开与生成结果 | `surveys.js` 模块内存 | 详情更新、折叠和栏目往返保留；整页刷新清空 |
| 论文搜索与范围、经典搜索 | `library.js` 模块内存，按页面区分 | 更新列表、栏目往返保留；整页刷新用现有默认范围 |
| 本人记录、待读清单、导学覆盖层 | 原有 notes/guidance 协议 | 仅现有显式保存/导入/确认等动作写入 |
| 单篇综述内部图、路径和阅读位置 | 原有 `survey-map-v1:{articleId}` 与既有 helper | 本轮不改字段、清理策略或保存语义 |

不增加 localStorage/sessionStorage 键，不将界面状态写入研究记录。不保存另一个冗余的 article 对象副本；视图保存 ID，渲染时从当前真实数据解析。

书架初始化先使用合法的模块内存主选择，其次读取既有 session key，再回退到数组首篇；session 读写失败不能覆盖本会话已经选择的对象。刷新后模块内存自然清空。

## 2. 综述目录搜索与选择

搜索字段为 `displayTitle/title/shelfLead/brief/scope/year`，trim 后不区分大小写，空查询匹配全部。显示“匹配 M / 共 N 篇”。每次搜索只更新目录结果，不重新创建整个书架、任务表单或已显示的文章详情。

| 触发 | 结果 |
|---|---|
| 搜索仍包含当前文章 | 保持选择和关联对象 |
| 搜索不包含当前文章 | 右侧保留当前文章；显示“当前详情不在搜索结果中”，提供清除搜索；不自动换主选文章 |
| 搜索零结果 | 目录显示“没有匹配的综述”和清除动作；已有详情仍可阅读 |
| 点击另一目录项 | 更新主选择及既有 session key；目录输入与滚动不丢；恢复该文章合法的关联选择或取首个关联对象 |
| 从文章或章节返回书架 | 恢复模块内存中的目录、主选择和关联对象，不强行清除筛选 |
| 整页刷新 | 主选择从既有 session 读取；其他视图状态恢复默认，不承诺持久保存 |
| 数据不含已选 ID | 回退第一个真实文章；无文章则显示数据空态，不创建空关系面板 |

文章详情默认使用原数组第一篇是回退规则，不标为“推荐起点”。目录条目是原生 button，可用 Enter/Space；实际选中同时有文字/边线与 aria 属性。

点击文章时焦点保持在目录按钮；不把焦点自动拉到详情或把页面滚到顶部。使用短 `aria-live=polite` 提示“已选择：题名”，不要将整篇介绍和关系文本设为 live region。

## 3. 关联对象选择

解析关系时同时检查两端文章存在、另一端不同于当前文章。依据另一端 ID 建立唯一选项，顺序沿用原 relations 首次出现的顺序，不据连接数量生成重要性排名。

选择某个关联对象只更新关系区；主选文章、目录和任务输入保持不变。该对的全部关系依原顺序完整展示。选中文章属于 to 端时，将 from/to unit ID 对应调换到当前/关联两侧，不能将另一篇的章节链接标在本篇下。

关联对象超过 8 篇时提供搜索，字段为另一篇的题名、年份和相关关系 displayLabel。输入只过滤选择项：当前关联对象若不再匹配，选第一个匹配项；匹配为零时清空本次关系显示，并给清除动作。显示“匹配 M / 关联 N 篇”，主选择不变；清除后保留仍合法的选择，否则取首项。

没有关系时显示“尚未整理与其他综述的联系”，不意味着不存在学术关系；主文章入口仍然可用。无有效章节引用时保留已有 relation.reason，并显示“章节入口尚未整理”。ID 无法解析时不生成坏链接，记录可诊断信息；正式数据损坏需在交付中报告，不能当成正常内容缺失。

`origin=editorial` 明示编辑联系；未知 origin 用“关系性质未标明”。只有原数据和可靠依据支持 citation 才能称“引用”；不从年份、连接方向或语义相似度推断。关系 selector 显示的是文章，不把关系性质并入假事实。

关系中的章节链接沿用 `unitHash` 和 `rememberSurveyUnit` 的既有调用，不新增必读路径或将章节访问写为掌握。“切换到这篇”执行主选择更新，将对应目录项滚入列表可见区；若被目录搜索排除，清除目录搜索并提示原因，焦点转到新选中项。

## 4. 阅读任务生成与复制

| 状态 | 必须呈现的行为 |
|---|---|
| 初始 / 折叠 | 入口可识别；任务表单未自动提交 |
| 展开 | 类型与输入可操作；关闭后输入不丢 |
| 空白或只含空格 | 拒绝生成，错误靠近输入并聚焦输入；不能生成空模板 |
| 合法输入 | trim 后生成；最长 500 个字符，限制及剩余行为清楚，不静默截断 |
| 已生成 | 预览显示完整文本；“复制任务”可用；显示“任务已生成，尚未复制” |
| 修改类型或文本 | 保留旧预览，提示“输入已修改，请重新生成”；禁用旧文本复制按钮 |
| 重新生成 | 更新预览和生成输入快照，恢复复制按钮；清掉旧的复制成功提示 |
| 点击复制 | 只复制当前有效预览快照；等待 clipboard Promise 后判成功或失败 |
| 复制失败 / API 不可用 | 文本保留，提示“未能自动复制，可选择下方文本手动复制”；提供选中文本动作，不误报成功 |
| 复制成功 | 提示“已复制任务文本，请在 Agent 中执行”；不能写成检索/制作完成 |

生成无网络请求；本轮不执行用户填入的 URL，不调用插件，不初始化个人记录。输入以 textContent/value 处理，不通过 innerHTML 拼入任意用户文字。

生成结果持有单调递增的 `generationId`；每次生成新文本都换 ID。点击复制时捕获文本快照和 ID。用户可在异步剪贴板请求等待期间继续编辑、生成新版本；旧 Promise 完成只可提示“上一版任务已复制”，不得覆盖当前新预览的复制状态或重新启用旧版本操作。相同版本防止重复提交。验收含竞态：A 复制尚 pending→编辑并生成 B→A 完成，B 仍是页面当前版本，并明确指出 A 才是剪贴板内容。

## 5. 论文范围、搜索与经典索引

论文 `primary/secondary/expanded/all` 的数据选择继续调用 `routePaperGroups`。范围按钮代替 select 后保留同一语义；范围改变保留当前 query，重算分组和计数。默认主方向不存在时沿用现有 scopes 的首个合法项，不创建空 primary。

搜索继续使用 `paperSearchText`，不缩减已支持字段。零结果明确表示当前范围下没有匹配，提供“清除搜索”；无查询且当前范围无数据，提供其他合法范围入口。空查询不会把非经典论文混入经典，也不会将待读清单混入公开库。

更新只作用于 controls 的选中状态、计数和 results；不能对整页调用 `renderPapers`，否则会销毁待读清单未保存输入。在同页重算及宽度变化中，待读输入 DOM 保持原节点。跨栏目返回仅恢复本包列出的搜索/范围状态，个人表单跨页草稿沿用原实现，不扩展为新的持久草稿功能。

经典组 ID 由 group.key 产生稳定且本页唯一的 DOM ID，例如 `foundation-group-{编码后的key}`。主题按钮定位当前可见组，滚动后聚焦其标题，不改 location.hash，不新增历史项。搜索更新主题匹配数与 disabled，不能保留指向已移除组的按钮动作。

## 6. 壳与 CSS 隔离

在 `renderApp` 的解析与布局判定接缝设置并明确清除目标页类。建议新增：

- shell：`is-browse-polish` 仅 home/surveys/papers/foundations；`is-survey-shelf` 仅列表路由 `#/surveys`，不用于单篇/无效文章详情。综述主页不设置 `is-graph`，确保栏目侧栏正常显示。
- view：`survey-shelf-view` 仅 surveys，用于解除外层 `.survey-view` 的旧最大宽度；跨到 survey 或其他页面必须清除。
- page：`lib-catalog-page` 加 `is-papers/is-foundations`；书架内框 `survey-shelf-page`；首页沿用 `lib-home-reader`。

这些名称为实现建议，语义边界为硬约束。`renderApp` 每次解析路由时先由本次有效路由重新设置全部目标壳/view/page 类，然后才能处理非法路由和不存在实体的 early return。无效 URL 和缺失的论文/综述/材料 ID 都不得继承上页临时宽度、旧选中或书架布局。单篇图保留 `is-graph`，正文保留 `is-reading`；A1 仅将 surveys 从图谱分类移入浏览分类。

章节/条目定位使用原生 DOM 支持的操作。`childNodes` 是 NodeList，调用数组查找前须转换；测试中的数组桩不能掩盖浏览器无 `.find()` 的事实。经典主题跳转、清除综述搜索后的定位和关联篇切换均应在该条件下正常完成。

样式集中在目标页面块，检查当前文件尾部覆盖规则。不要全局改 `.lib-page`、`.survey-view` 或 `.lib-paper-item` 来影响所有路由；复用行组件时以目录根类限制新 grid。删除已无引用的书架 SVG 样式需先核查使用范围，不能删同名近邻的单篇图样式。

## 7. 事件与记录安全

优先使用原生控件和元素事件，不新增全局按键监听。需要窗口事件或观察器时接入现有 `cleanupCurrentPage`，离开页面注销；不要依赖刷新释放资源。

视图保存不触发 `v3Persist`、导学写入或单篇读序更新。导出保持显式点击；待读添加/移除仍由原按钮执行。状态核查使用隔离 origin 或内存 mock，不读取用户现有记录作测试资料。跨页来路、safeExternalHref 与外链安全属性按 READING-015 04 保留。
