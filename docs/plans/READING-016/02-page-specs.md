# 页面与组件规格

版本：v1.2 · 2026-10-05。A1：四个目标页的宽内框在侧栏右侧主区居中，综述主页恢复统一侧栏。几何、字号与收拢规则引用 [01](01-design.md)，交互状态引用 [03](03-interactions.md)。

## S01 · 综述书架

路由 `#/surveys`。主任务：选择文章、理解定位、查看与另一篇的关系，再进入文章或相关章节。

```text

┌─综述目录 340─────────────┬─当前综述详情───────────────────────┐
│ 搜索题名、关键词……        │ 年份 · 当前整理情况                  │
│ 显示 M / N 篇 · 清除搜索  │ 完整题名                             │
│                         │ 这篇解释什么、覆盖什么                │
│ 年份 · 状态              │ [进入这篇综述 →]                     │
│ 完整题名                 │                                     │
│ 一句内容定位             │ 与其他综述的联系 · N 篇                │
│ ……                      │ [关联综述选择器 ▾]                   │
│                         │ 关系名称 · 关系性质                   │
│                         │ 完整互补说明                         │
│                         │ 当前综述章节 ↔ 关联综述章节            │
│                         │ [查看关联篇] [切换到这篇]              │
└─────────────────────────┴─────────────────────────────────────┘

基础发展入口 · 查看知识脉络图
想了解其他领域？ [生成阅读任务 →]
```

### 目录

显示全部 `SURVEYS.articles`，保留数组顺序。默认优先恢复本会话合法主选择（含既有 session 选择），无合法选择时取数组第一篇；不凭年份、引用量或题名新造推荐排序。

每项包含 `year`、状态、`displayTitle ?? title`、`shelfLead ?? brief`。完整题名和定位自然换行、不用省略号，不以固定高度裁掉文字；较长内容通过目录局部滚动承载，不再给每项增加展开控件。详情中也完整保留定位。

当前选中项以轻底、左线、字重和 `aria-pressed` 标明。目录标题、搜索与计数在目录上部；双栏时仅条目列表可滚动，最大高度可用 `clamp(360px, calc(100dvh - 220px), 760px)` 作为起点，不锁定整页高度。页高过小或转单栏时恢复自然文档流。

当前数据没有独立的领域分组字段，三篇均为 Agent 综述。本轮不显示空的“领域筛选”控件；领域词通过题名、简介和 scope 搜索。后续内容任务补充可信分类后，才增加该筛选，不从相似题名自动推断领域。

### 文章详情

年份和真实整理状态放在题名上方；内容定位、scope 和主要入口依次排列。正文与图表核验限制仍在相关位置清楚表达，可通过“范围与限制”查看 `limits`；不得将 `partial` 改成完整或已读。

`candidate` 的入口文字为“查看来源与待制作说明”；有现有阅读单元的文章为“进入这篇综述”。两者都进入已有 `#/survey/{id}`，不直接强跳首个 unit，也不新建路由。

详情区自然增长、由整页滚动承载；不增加固定高度的第二个阅读滚动框。切换文章时保持目录滚动与输入，更新详情中的题名、范围和关系。

### 关系对照

取与当前文章有关的 `SURVEYS.relations`，按另一端文章 ID 合并选择项。标题“共 N 篇”统计独立关联文章，不能把多条关系数当文章数。

选择项的文本包含年份、完整题名；选定后在对照区顶部再次完整换行显示关联文章题名，不能让原生控件的宽度成为唯一识别入口。关联文章超过 8 篇时，在原生选择器上方显示短搜索框“搜索关联综述”；通过筛选选项支持查找，不引入自定义弹层或 combobox 框架。没有超过阈值时不显示该输入。

一次只呈现选定的一对文章。若同一对有多条已整理关系，在这一对的区域内逐条展示，不能只保留第一条。每条包括 `displayLabel`、`origin/kind` 的诚实标签、完整 `reason`，及两端 `fromUnitIds/toUnitIds` 对应的真实章节链接。

当前三条关系均为 `origin=editorial`、`kind=complements`，显示“编辑整理的内容互补”。即使另一篇年份更新，也不加“取代”“引用”或“必须先读”的隐含箭头。两端章节使用并排块和轻连接符号表达对照，不使用带先后含义的方向箭头。

当前文章恰好是关系的 to 端时，仍将其章节放在“当前综述”一侧；另一端放“关联综述”一侧。每侧题名和章节入口明确，不用“一端/另一端”作为唯一身份。

“查看关联篇”进入文章；“切换到这篇”留在书架并改变主选文章。删除书架全局 SVG、右侧全量展开列表及“按文字浏览全部文章关系”的重复入口；关系数据、原因和章节链接全部保留。

## S02 · 拓展综述阅读任务

位置：书架浏览区后，知识脉络入口下方。默认收起，使用一条轻量说明与“生成阅读任务”入口；不做抽屉或模态框。

```text
想了解其他领域？ 根据领域、关键词或指定文章准备阅读任务。
[生成阅读任务 →]

展开后：
输入方式  (领域) (关键词) (指定文章)
你想了解什么
[主输入框………………………………] [生成任务]
生成可交给 Agent 的任务文本，需复制后执行。

结果：任务预览                    [复制任务]
[只读、可选择的任务文本……]
复制成功或失败的真实状态提示
```

面板最大 1040、内边距 24、浅纸色底、细边框、圆角 6。输入方式用原生 radio 加 fieldset/legend，视觉上为三个紧凑选项，避免占一整列的大 select。主输入与按钮基线对齐，空间不足时按钮自然换行，控件最小高度 44。

类型对应 placeholder：领域“例如：多模态 Agent”；关键词“例如：长期记忆、工具调用、评测”；指定文章“输入文章题名、DOI 或公开链接”。它们是输入示例，不是推荐结果。无 URL 自动解析、联网验证或上传。

沿用现有任务模板的实质要求：文章身份与版本、全文/关键图表/附录、有限且有理由的选文、章节覆盖、原文定位、角色区别、缺口说明和本地来源约束。允许整理模板格式，不删除这些要求。

生成与复制分成两步，预览固定为当前输入生成的文本。折叠再展开保留输入和结果；更新输入后标记旧预览并要求重新生成，详见 03。结果使用可选择的只读 textarea，最小约 8 行、内部换行；长任务文本仅在预览局部滚动。

### 页头与工具栏

页头左侧为题名和短说明，右侧为“导出我的记录”的次要按钮，导出功能仍调用 `downloadMyNotes`，只在当前 `v3Available()` 条件下出现。储存错误/不可用提示继续可见，不用视觉成功状态掩盖。

四个范围使用一组原生按钮，当前项 `aria-pressed=true`。它们是互斥范围控件，不声明成具有复杂方向键契约的 ARIA tabs。键值仍为 `primary/secondary/expanded/all`；缺少对应 active 方向时不产生该按钮。初始默认范围沿用当前规则。

检索在范围行之后、结果之前。搜索框默认 420–560，不随页面全宽拉长；计数和当前范围紧邻作用对象。取消上方“经典书目”的等权按钮，相关入口放在页尾，栏目侧栏入口仍可见。

### 条目

宽时主列放题名与完整 `lead`，窄元数据列放当前 `badgeLine` 信息、发表/提交时间及本人状态。这些字段来自现有 helper，不能依据本轮审美改写时间定义、推荐深度或本人状态。

元数据列不创建新的空标签。本人未标记时仍按现有规则不显示“我的状态”；来源覆盖和本人掌握不能合并。长 lead 不截断，只限行宽；题名保持原链接，来自路线的 `context` 完整传递。

保留原整行点击的便捷行为，但点击链接/按钮和选择文字不触发额外导航。键盘主入口为题名链接，不重复添加整行 tabindex 造成双重焦点。

### 下部内容

`renderFoundationMaterials` 和 `renderReadingList` 必须保留。基础导读仍有完整题名与用途；“我的待读清单”仍有当前条目、备注、添加、移除及错误恢复，不能放进消失的页头或藏为不易发现的操作。它的表单最大 1040，不跟随 1536 拉得过宽。

## F01 · 经典书目

路由 `#/foundations`。页头继续说明“不绑定具体方向的基础经典”，现有“依据摘要、建议投入不等于已读”提示保留可见，字体不小于 14。

宽屏左侧增加“主题”局部索引 176，右侧为搜索、计数和已有分组列表。索引直接来自 `foundationGroups(renderLibrary)`：分组 key、题名、组内条目数及原顺序；不添加推测主题。组标题和 note 均完整保留。

```text
经典书目 · 用途与覆盖说明

主题索引                 搜索经典论文 [………………] 共 N 篇
架构与预训练 · N          架构与预训练
其他已有主题……           分组说明
                        完整题名 / 用途          依据与时间
                        ……
```

主题索引负责跳到分组，不是第二个隐藏过滤器。点击使用页内按钮滚动并聚焦，不把普通锚点写进 hash 路由。索引可以 sticky，顶部 24；不要求引入 IntersectionObserver 跟踪当前组，最后点击项不能标成自动当前位置。

搜索只保留匹配的分组；无匹配条目的主题保留名字、显示当前匹配数 0、禁用跳转并说明“当前搜索无匹配”。总数为筛选结果，分组数不得误用搜索前数量。清除搜索后恢复主题和原组内顺序。

宽度不足时索引转为工具栏下方的换行按钮组。列表条目复用 P01 的阅读行，但按剩余宽度决定分列；现有 11 篇及本人明确标记、摘要级判断完整保留。

## H01 · 首页

路由 `#/home`，实际接缝为 `renderHomeReader`，不重写历史 `renderHomeLegacy`。

顺序保持：标题与导语 → 三步学习动线 → 建议起点与两条方向 → 四个用途入口 → 其他入口。

整体上限 1728，在侧栏右侧主区居中。两区间距 32，先扣除间距，再将剩余宽度按 60/40 分给建议起点与方向区；起点内边距 28–32，完整理由、自检、主要入口和路线入口都保留。起点主文最大 780，避免加宽后出现一行跨过整块的说明。

两条方向保持当前主方向与第二方向身份及顺序。方向说明从当前较小字号提升到 15–16、行高约 1.8，题名 18；不因为右侧剩余空间加第三条方向或新推荐。

三步动线保留三列，短标题和说明有共同基线；不加高大横幅。下方四个入口继续两列，栏间 32–40、行间 32，入口的题名、用途、真实子入口保持完整。导语、起点、四个入口使用同一外框左边缘。

本人在读入口与待确认导学调整仅在现有真实条件下出现。保留 `resolveHomeFocus`、`computeEffective`、`activeDirections`、`featuredTechnicalRoutes` 等 helper；不把现有技术身份改成等权必学。不凭空补“最近阅读”“完成率”或统计卡。
