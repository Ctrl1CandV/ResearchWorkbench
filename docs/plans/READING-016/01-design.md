# 设计决策与视觉系统

版本：v1.2 · 2026-10-05。原设计经独立复核 GO；A1 按用户实施后截图修正居中与综述导航，见 I4 证据。A1 由主会话审查和修复，未追加独立审查。

## 1. 用户目标与参考角色

主要读者是读研初期、尚在认识领域的本人。综述页首先帮助选择一篇合适的文章，再理解它与其他文章之间的内容联系；论文与经典索引帮助查找对象；正文页负责连续阅读。首页提供可信起点及后续入口。

| 依据 | 角色与可用结论 |
|---|---|
| 用户四张截图及说明 | 精确标出需要调整的区域；确认正常桌面下留白过多、关系重复和表单比例问题 |
| 用户对前轮的基本认可 | 暖纸色、深绿强调和阅读气质的延续依据；不等于认可每一处当前布局 |
| 当前正式渲染代码 | 真实字段、行为和接缝依据；源码尺寸不是实际视口测量 |
| frontend-craft v0.2.0 的布局、视觉、工具界面、阅读及验证参考 | 内容关系先于布局；目录页与正文宽度分开；用实际画面判断完成度 |
| READING-015 阅读 Demo 与实施记录 | 前轮风格与行为背景；本轮没有重新进行同屏标杆比较 |

未使用新外部视觉标杆，没有新增视觉素材。多条目样例只用于后续隔离核查，不属于真实内容库或本人进度。

## 4. 可直接实现的宽度规则

所有数值为 CSS px。布局最大宽度是默认值，允许在真实桌面核查后按第 7 节的有限调整规则修订。

设 CSS 视口宽度为 `V`，侧栏显示时宽度 `S=208`、按现有响应规则收起时 `S=0`，页面横向内边距 `G=clamp(32, 0.025×V, 64)`。四个目标页统一使用可用宽度 `A=V-S-2G`；内框宽度为 `W=min(A, 页面上限)`。A1 将内框在主区居中，左右剩余空间均为 `(A-W)/2`，起点为 `S+G+(A-W)/2`。不得用最小宽度撑破页面。

| 页面 | 默认上限 | 起排与内部布局 |
|---|---|---|
| 论文索引 | 1536 | 在侧栏右侧主区居中；纵向列表，宽时主内容加元数据列 |
| 经典书目 | 1536 | 同上；足够宽时主题索引加列表 |
| 首页 | 1728 | 同上；建议起点与两条方向并排，下方保留两列入口 |
| 综述书架 | 1728 | 统一栏目侧栏；主区居中；目录 340、栏间 32、详情弹性 |
| 阅读正文、单篇图、领域图等非目标页 | 沿用实际已实施规则 | 不接受目录页的新宽度与对齐选择器 |

目标页使用各自宽内框的 `margin-inline:auto`。达到上限后多余空间均分到主区两侧，避免上一版全部留在右侧造成偏左。保留上述宽度上限和独立文字行长，不退回旧的 46rem 窄目录。综述主页使用统一侧栏，清除原先书架专用的顶栏几何覆盖。

示例预算：V=1440 时 G=36，带侧栏 A=1160；V=1920 时 G=48，A=1616，论文索引宽 1536、首页宽 1616；V=2560 时 G=64，A=2224，论文索引宽 1536、首页宽 1728。这是设计计算，不是实页测量。

宽目录不意味着无限延长文字：论文用途/摘要最大 760，首页起点正文最大 780，综述简介与关系说明最大 800；字段缺少时自然收拢，不为对齐添加空内容。纸色分隔线可跨完整条目，长段落仍在各自限宽中。

## 5. 内容宽度不足时的让位规则

以内容区的可用宽度判断，实施者可用局部容器规则或等效 CSS；不得仅按截图的物理像素判断。

- 综述书架内容宽度 ≥1000：目录 340、间距 32、详情至少 628；低于 1000 时目录在上、详情在下，不缩小文字挤成双栏。
- 论文列表宽度 ≥1056：元数据列 220、间距 32，其余为主列；更窄时元数据回到题名下。
- 经典内容区宽度 ≥1280：主题索引 176、间距 32、列表使用余宽；否则主题按钮转为列表上方的换行导航。内部论文行按其实际剩余宽度判断是否分列。
- 首页内容区宽度 ≥1056：先扣除 32px 栏间距，剩余宽度再按 60%/40% 分给建议起点和方向区，即 `主区=(W−32)×0.6`、`方向区=(W−32)×0.4`；低于该值时上下排列，阅读顺序不变。
- 关系的两端章节入口总可用宽度 ≥720 时并排，否则上下排列并写清各自文章身份。

本轮不安排手机专项。上述收拢是桌面普通窗口改变大小时的基本容错，不构成手机验收通过的声明。

## 6. 文字、颜色和细节

延续当前 `--lib-*` 功能色和字体栈，不引入第二套主题。下面数值仅作用于四个目标页面。

| 角色 | 默认规格 |
|---|---|
| 页面标题 | 32、标题字体、600、行高 1.4 |
| 选中综述题名 / 首页起点题名 | 26、标题字体、600、行高 1.5 |
| 论文条目标题 | 20、标题字体、600、行高 1.5 |
| 组标题 / 方向标题 | 18、界面字体、600、行高 1.5 |
| 主要介绍、条目用途、关系说明 | 16、400、行高 1.8 |
| 年份、标签、计数 | 13、400–600、行高 1.6；结论和限制不降至该档 |
| 控件 | 14、最小高度 44、允许长标签换行 |

间距档为 8、12、16、24、32、48、64。组内用 8–16，组件间 24–32，大区间 40–48；页首到主任务区不加展示型大空白。边框与圆角沿用 4–6 档，默认无投影。深绿面积集中于首页建议起点和主要动作；综述目录选中用轻底、左线及字重共同表达。

正文与实际底色的对比目标为 4.5:1，适用大字和必要控件状态为 3:1；本包只规定目标，未宣称新组合已计算或认证。悬停不改变尺寸，焦点清楚可见，禁用保留可读标签与原因。

## 7. 允许现场调整的范围

真实主桌面画面若仍显松散，可调整：页面上限 ±128、目录宽度 320–380、栏间距 24–40、区间距 32–48。调整必须同时检查完整长题名和受影响相邻区，并在阶段报告记录最终值及原因。

以下决定不在随手调整范围：恢复全局关系网与重复关系展开项、把论文改成无顺序的等权卡墙、删除覆盖说明、改变目录与正文的任务分工、改实体 ID/个人记录、扩大产品范围。此类变化应先修订设计，不能只在最终截图中出现。
