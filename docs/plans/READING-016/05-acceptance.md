# 桌面验收与证据

版本：v1.3 · 2026-10-05。A1 已审视用户提供的首轮四页截图，修正后画面尚未复核。已执行层级、证据与未完成项记录在 [`REVIEW.md`](REVIEW.md) 与 [`evidence/`](evidence/)，不把 DOM/CSS 检查记为视觉通过。

## 1. 验收范围

目标环境是用户日常桌面、正常窗口、浏览器 100% 缩放；若观察可用，记录 `innerWidth/innerHeight/devicePixelRatio` 和缩放，不把 3840×1970 图像尺寸当 CSS 视口。主机 Computer Use 首次取证因 URL 确认中止。后续用户回传的四页图已完成视觉自检；未实测 CSS 视口，也未取得 A1 修正后的新图或备用视口图，不推定尺寸。

普通桌面补充视口为 1440×900，仅检查综述与论文两个代表页的收拢和长题名。若主环境已在 1440–1600 CSS px 范围，不重复同类截图；另补一次更宽桌面观察以回应用户的大屏问题即可。

手机专项、200%/400% 缩放、多断点矩阵、性能基准、全站自动浏览器回归均不列入本轮门槛。轻量交互和内容边界仍检查。用户豁免项目标为“用户豁免 / 未执行”，不写“通过”或转成未完成的阻断项。

## 3. 最小实页核查

主桌面四页各留一张正式 after，长页额外观察下部即可，不为每个滚动位置机械生成完整矩阵。综述至少补一张任务展开图；普通桌面补综述、论文两张代表图。发生问题才补该状态图。

轻量操作顺序：

1. 书架搜索并选文章，切换两个关联对象，打开一端章节后返回；切换主文章，检查两端章节身份。
2. 展开任务，生成、修改、重新生成和复制；复制拒绝用隔离 mock，不修改用户浏览器权限。
3. 论文切换合法范围、检索英文题名、零结果后清除；先在隔离待读表单输入草稿，筛选后确认原输入仍在。
4. 经典点击非首主题，确认定位与 URL；搜索、清除，观察主题匹配数。
5. 首页查看下部与代表入口；短路由循环：书架 → 单篇图 → 正文 → 论文 → 首页 → 错误页，确认宽度类已正确清除。

Tab/Enter/Space 只覆盖新增文章按钮、范围按钮、任务表单、主题跳转等实际控件；不开展全站无障碍认证。对新变化的文字/底色、选中和焦点组合做必要检查，未执行的计算不得标合规通过。

## 4. 内容与存储检查

本轮公共内容文件按计划只读；比较前后源码摘要即可确认没有新增/删改文章事实。条目数量仍须在渲染里核对，不能仅由源文件未变推断没有漏显示。

个人状态、待读输入与导学覆盖核查仅用隔离合成值，明确标注“合成验收数据”；不得导出当前用户记录来证明功能。新 view state 不写 v3/guidance；既有 shelf:selected 写入属于原视图协议，不误判为个人记录写入。
