## 本轮要解决什么

用户基本满意前轮视觉效果，提出四类增量调整：综述数量增加后的选择与关系展示、综述阅读任务表单、论文索引顶部区域、首页及经典书目的大屏留白。使用情境是桌面正常打开、浏览器 100% 缩放。用户已豁免手机专项、200%/400% 缩放实验及不必要的复杂测试。

本包采用一套明确方案：综述目录加详情、当前两篇的关系对照；目录页扩大工作区域，文字单独限宽；论文操作按作用对象重组；首页与经典书目调整比例和对齐。A1 根据用户截图，将四页宽内容区统一居中于栏目侧栏右侧，综述主页恢复栏目侧栏。保留暖纸色、深绿强调、现有标题字体角色及连续阅读体验。
