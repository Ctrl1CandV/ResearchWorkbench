## 阶段 A–C 交付

### A · 首页与综述阅读

- 首页把建议起点、阅读目的、理解标准与各栏目入口放在同一阅读顺序中；保留每日精选入口和暂停状态，不编造阅读进度。
- 综述书架用文章节点、带语义的关系线和选中预览说明文章之间的关系；保留可操作的同源文本列表。
- 单篇综述提供关系图、章节列表和建议读序三种浏览方式。关系理由标出原文关系或编辑解释，并保留出处定位。
- ACL 的 benchmark-dimensions 阅读单元继续呈现完整讲解、五维交互图、比较表和来源限制，没有换成简化样稿。
- 综述覆盖范围展开后会列出“已核读”“站内已讲解”“尚未讲解”三组实际章节；`partial`、待核图表和未解决事项仍明确保留。

### B · 方向、路线与可扫描书库

- 方向页突出两条 active 方向，延后方向仍可从旧入口回查。
- 路线页把当前起步步骤放在前面；理解课题和按需阅读可在页内切换，已有路线分析继续可达。
- 路线 hash 支持 `section=start|topic|archive` 与合法步骤 `step`；未知参数和非法组合继续遵守既有拒绝规则。旧路线 URL 仍默认显示起步。
- 论文书库可按主方向、第二方向、拓展和全部范围浏览；搜索空结果可恢复。按路线分组的论文链接保留显式 `route/track` 来路。
- 经典书目沿用可扫描分组与搜索；五篇基础导读在“基础导读”组提供统一回查入口。

### C · 阅读卡、其余综述与既有栏目

- 论文与材料继续按实际覆盖深度显示简读卡、原文依据、精读定位、讲解和来源限制；目录、下一步、返回路线和原文入口沿用现有数据。
- 五篇基础导读各有确定入口，详见下表。
- 三篇综述均保留各自原有语义、章节来源、关系和读序；FCS 关系图的选中关系区在窄屏默认收起，图中关系编号可自动展开并聚焦对应依据。

- 页面切换时清除综述专属的 `survey-view` 类，避免共享容器把综述样式带入首页、论文库或技术页。

## 路由、视图与个人记录边界

- 旧页面 hash 和论文、材料、技术、综述单元入口继续解析。路线、书库分组与读序链接只在数据明确提供来路时带上下文；直接深链不推断默认路线或读序。
- 综述图的视图与选中单元只保存在既有 `survey-map-v1:{articleId}` 会话视图键。显式从建议读序进入的已访问单元，可在同一路径的浏览器后退/前进中保持读序。切换为自由探索会清除当前续读路径；此后回退到此前读序单元会按普通全单元顺序显示。该行为符合“自由探索清除当前续读”的视图协议，但本轮没有把跨自由探索的路径恢复作为已验收能力。
- 图中关系编号会先展开窄屏折叠的关系说明，再滚动并聚焦对应理由。
- 没有重命名、迁移或初始化 `research-workbench:v3`，没有扩展导学覆盖层存储。真实浏览器检查未打开记录编辑/保存表单，未通过工具读取或改写真实用户记录；记录键与显式保存契约由内存 mock 测试覆盖。
- 地图选择、缩放、滚动与阅读模式仍是视图状态，没有写成“本人已掌握”。
