# 01 · 设计决策 v0.3

本版沿用用户已认可的v0.2信息架构；配色与文案增量见05。

## 1. 问题本质

### 学习问题没有成为页面的组织单位

内容按生产阶段和数据模块连续堆叠，用户必须自行判断前置背景、学习目的和先后关系。首页的具体课题解释出现得过早，方向页把起步步骤放在研究分析后，论文库按资料来源说明开场。新手缺少做这些判断的背景。

### 入口信息与讲解信息使用相同展开方式

选择时需要少量可比较的信息；理解时需要完整解释。当前把长解释塞进入口，把短摘要套上完整长文的目录/表单，两个任务都显得费力。信息量应按任务配置，正文不设统一字数上限。

### 页面没有稳定的空间和视觉语法

窄列首页与通栏综述卡并存；主标题、栏目标题和链接的字体角色漂移；每个子块各自加边框、竖线和标签。需要统一页面级布局、排版角色与信息优先级，再决定组件样式。

### 图、内容与行动之间有距离

文章关系逐边重复节点；文章内图被工具栏、滚动框和下置详情拆开。读者难以同时看到整体、选中节点及下一步。关系图应是一种解释工具，节点选中后的短说明与图同屏，充分正文进入独立阅读页。

## 2. 三种方案比较与裁决

| 方案 | 收益 | 代价 | 裁决 |
|---|---|---|---|
| 全站学习任务优先 | 降低新生选择负担 | 容易形成作业/打卡暗示，压缩探索与回查 | 用于首页和路线页 |
| 全站书库优先 | 信息规整、易扩展检索 | 仍要求用户先知道想读什么 | 用于论文库和经典书目 |
| 全站地图优先 | 关系直观，具有鲜明特征 | 长文与简单查找也要经过复杂图操作 | 用于综述总览、单篇结构和背景地图 |

采用分工：定下一步 → 看清关系 → 连续理解 → 回查比较。统一字体、间距和导航，允许各页布局不同。
视觉方向：适合长时间中文阅读的清晰学术工作台。强调色用于当前选择和主要阅读入口；独特性集中在具有语义的关系图及图文联动。页面采用明亮中性底色，减少深色侧栏的视觉重量，保留研究阅读工作台名称。

## 3. 页面职责与主要行动

| 页面/现有路由 | 读者问题 | 默认主体 | 主要行动 |
|---|---|---|---|
| 首页 #/home | 各部分怎么帮助我？现在从哪开始？ | 全站学习路径、真实起点、两方向概述、栏目具体用途 | 开始建议阅读；有本人在读记录时提供继续阅读 |
| 综述 #/surveys | 现有综述覆盖什么？彼此有什么联系？ | 当前主题的唯一文章节点图＋选中短说明 | 打开文章脉络 |
| 单篇 #/survey/:id | 这篇如何展开？从哪节读？ | 分组文章结构图＋选中章节说明 | 进入章节阅读 |
| 综述单元 #/survey/:id/unit/:unit | 这一部分究竟讲什么？ | 连续正文、局部解释图/对照表、章节目录 | 读下一节或返回原图节点 |
| 方向 #/directions | 两条方向分别研究什么？ | 相同字段的并列比较 | 查看起步路线 |
| 路线 #/route/:id | 怎么逐步建立这个问题的认识？ | 问题定位、起步步骤、当前步骤目的与掌握标准 | 阅读选中步骤 |
| 论文 #/papers | 哪些论文与我当前学习有关？ | 当前方向起步/拓展分类与紧凑列表 | 打开阅读卡 |
| 论文卡 #/paper/:id | 讲什么？为何值得读？我能理解到哪？ | 与内容覆盖相适应的正文 | 阅读、按需记笔记、继续路线 |
| 经典 #/foundations | 哪些基础值得补？ | 既有主题分组、基础作用、具体论文 | 打开对应导读 |
| 技术 #/learn 与单元 | 当前哪项技术能帮助理解/实践？ | 默认三条路线、现有可用单元、能力和掌握标准 | 学当前所需单元 |
| 精选 #/brief | 查过去的信息线索 | 历史简报，简短暂停更新说明 | 回查历史 |
| #/map、#/guidance | 背景概念回查、本人导学调整 | 原能力保留为次级入口 | 延续已有任务 |

首页固定建议仍从现有生效库 startHere/方向起步步骤推导；不另建静态推荐真相。无个人记录时用“建议起点”，不显示伪造完成量/今日任务/继续进度。只呈现本人显式标记的在读状态，不推断掌握。

## 5. 讲解和范围

摘要卡保持摘要卡：标题、研究问题、基于现有依据的摘要说明、阅读价值、待进一步理解的问题。不能在缺正文时填入虚构机制、实验或例子。
正文卡/综述单元保留问题动机、术语、机制、贯穿例子、条件、比较与限制。结构按内容决定，不强制每篇填满同一模板。
作者转述、编辑联系和教学例子仍可辨识：正文必要处短标注，出处通过编号入口按需回查。来源与内容范围不等于个人阅读状态。

## 6. 原型覆盖边界

样稿用公开产品内容快照验证真实标题、段落、表格、长路线与图节点；展示首页、综述关系、文章结构、真实章节正文、方向、论文/经典列表及技术入口。它不验证生产路由迁移、存储、导学覆盖层、完整键盘/屏幕阅读器流程、原 PDF 事实或图表。
视觉认可之后才冻结样式和页面结构；产品代码独立实施与验收，不能把样稿可点击当作产品功能通过。
