# 02 · 视觉与交互规格 v0.3

基线 f0312c7。用户已认可整体布局与阅读密度；本版按反馈增强配色，作为实施依据。尺寸仍需在真实产品内容中逐页验收。桌面长时间阅读优先；不建设移动端专门功能。

## 1. 空间与字体

### 页面骨架

| 场景 | 1440px 桌面初值 | 空间用途 |
|---|---|---|
| 导航 | 左栏 208px，页面外侧 46px | 栏目名、当前栏目；方向上下文仅在相关页展开 |
| 首页/列表/方向 | 主区域最大 1320px | 支持并排比较和学习入口；避免全页窄单列 |
| 关系探索 | 余宽给图，短预览 290–306px，间距26–30px | 图保持主体；短预览解释当前选择与下一步 |
| 阅读页 | 正文最大 760px，目录 210px，间距56px | 约35–42个中文字符/行；大屏增加外部留白 |
| 大屏 ≥1900px | 列表与图最大1400px；正文仍不超过760px | 增加图/对照的利用率，避免段落横跨屏幕 |

首页采用「横向学习动线 + 建议起点/方向概览双栏 + 2×2用途区」。首页整体保留足够信息，正文篇幅不靠卡片高度强制截断。

1280px 为最小重点桌面检查宽度；1440px 为主设计宽度；1920/2560px 检查最大宽度与空白。窄窗口在980px附近把图与预览上下排列；700px以下导航折成横向、正文单列。这些是基本防破版规则，不是本轮移动端设计投入重点。

### 排版角色

| 角色 | 初值 | 使用规则 |
|---|---|---|
| 中文与普通英文 | Microsoft YaHei / PingFang SC / Noto Sans CJK SC / Segoe UI / sans-serif | 全站一个系统字体栈，不按栏目切换宋体与无衬线 |
| 页面标题 | 32px / 1.42，600–650 | 每页一个；长学术标题可用27–29px |
| 一级内容标题 | 23px / 1.5，600–650 | 按正文逻辑分节 |
| 列表/节点标题 | 17–19px / 1.55–1.7 | 可换行，不横向挤压/省略核心题名 |
| 主阅读正文 | 18px / 1.95，400 | 段间约1.15em；不加满屏边框 |
| 页面说明/导航 | 15–16px / 1.75 | 行动与解释可快速扫描 |
| 辅助出处/元信息 | 12–13px / 1.7 | 不承载必须理解的学术结论 |
| 代码/公式 | 专用等宽/数学排版 | 只在需要语义的范围内使用 |

原站混乱来自字体角色、字重、大小和容器层级共同漂移，不能只通过改 font-family 解决。链接默认继承所在文字角色，靠颜色和下划线/箭头表达可点，不另用字体。

### 颜色和容器

底色 `#f6f8fb`，正文 `#172f3d`，次级正文 `#4e6575`，分隔 `#c7d5de`，交互强调 `#096c63`，浅强调 `#dceee7`。侧栏 `#e7eef3`，图区域 `#e9f0f5`；首页建议阅读区采用深青绿 `#14534f`、白色文字与金色顶边 `#d5ad68`。当前导航和选中节点使用明确的实心强调。完整规则见05及v0.3样稿。

普通段落不用卡片。组与组靠间距和标题；并列条目靠细分隔。实心容器主要用于建议起点、当前步骤、交互节点、必要教学例子。正文中的例子与来源信息不得层层嵌套三层卡片。

色彩只辅助表达，选中节点还用边框/文字/aria状态；本人已读不能与当前选中共用同一种无标注高亮。圆角5–7px、无装饰阴影、无背景动画。图的意义来自结构与联系，不来自光效。

## 2. 文章间关系图

当前仅三篇综述、三条主题互补边。使用稳定位置、唯一文章节点的 SVG连线＋HTML按钮，避免无意义力导向漂移与重型依赖。

- 每篇只出现一次。2024构建与2023概念放左侧上下，2026评测放右侧，构成互补三角。
- 每个节点只显示短题名、文章时点、视角关键词。正式完整题名、内容简述、价值和阅读入口由右侧提供。
- 互补关系使用无箭头虚线。边的简短题签分别为“两种架构视角”“组件与评价”“性质与测量”。均从当前 relations 的 reason 概括，不创造学术引用/依赖。
- 选中一个节点，右侧显示它与另外两篇的具体联系；展开能读到现有完整 reason 与相关章节入口。
- 图下用一句图例解释语义。关于读取工具、解析过程、任务执行状态的信息退出阅读流。
- 列表视图是同源可达替代：3篇文章和3条关系，不依赖视觉定位才能读懂。
- 单击/Enter/Space选中；Tab逐个进入；按钮名称包含题名与文章时点。重新渲染不能丢焦点。离开阅读后返回，恢复选中节点和页面滚动。

未来更多综述不在本轮提前建设通用图平台。节点超出当前三篇时需重新审核分组策略，不能把三点坐标直接扩成乱线。

## 3. 单篇文章结构与内部关系

分清三类关系，分层展示：

1. **主题归属**：原有 topicMap.groups 分成最多3个主要分组，分支线表达归属；章节号保留。分组属于编辑导读时明示，不能冒称原文分类。
2. **章节之间的解释联系**：来自 topicMap.relations。选中时突出相关节点，图中显示当前相关边及简短 label；右侧展开 reason，区分 author 与 editorial。默认不绘制所有交叉边。
3. **建议读序**：使用 readingPaths。切换读序模式时明确“编辑建议”，展示编号/方向和为什么接着读；不能把它复用成所有节点的先修边。

右侧限制为「所选章节题名＋lead＋进入阅读＋相关联系」；不把数千字正文塞在侧栏。附录默认收起，展开后进入同样的节点体系。详情打开、展开附录、返回地图时不丢选择。

独立样稿已表达主题分组、选中跨组连线、关联节点描边、带编号的关系解释、短预览与读序折叠。图/列表/读序三模式切换仍须在产品样板阶段补齐并单独视觉审查，不能声称原型已完成全部图交互。

章节正文里的知识图按内容选择表达：

- ACL基准维度：五个并列维度，每轴可展开细分与说明，点击跳正文定位；轴之间无顺序箭头。
- FCS记忆：结构/表示/操作三轴，保留已有选择解释，不缩成只含三个词的示意。
- 早期Agent构建：控制器/感知/行动表示组成，能看清输入、决策和行动关系；不得移植另篇架构的分类混合成“统一真理”。

现有原图未完成视觉核验；新导读图明确按已读文字构建，不能标作原论文图重绘。没有相应依据就不增加因果箭头。

## 4. 长文与阅读卡

阅读页顺序：返回上下文 → 题名/短覆盖 → 开篇导读 → 充分正文与局部图表 → 原文重点/思考问题 → 下一步。桌面目录在右侧，与标题/正文同一滚动文档。正文不得放入独立滚动容器。

- quick卡：用自然段解释现有摘要、阅读价值、待理解问题；不生成空的“机制/实验/结论”章节。
- quick交付标签为“简读卡”，依据另列“摘要”或“摘要及指定正文”；已有指定正文不升级内容深度，也不能误标成仅摘要。固定样例为Transformer、Beyond Frameworks、TOSEM接受标准三种。
- standard/deep卡：按已有章节、guidedReading、readingActions解释展开；所有有教学价值内容必须登记承接，不能只保留 lead。
- 目录只列实际章节；短卡0–2节时用精简辅助区，不做占据半屏的目录。
- 作者转述正常排版；教学例子/编辑联系在必要处用短标签辨识；出处编号展开定位。表格脚注与特定未核限制在表旁可见，不能全部藏入页底。
- 图表可较正文宽，但不能造成整页横向滚动；宽表局部滚动有边界提示。
- 个人笔记入口放辅助区，已有记录先显示预览；编辑时才展开表单。原保存、校验、导出流程完整复用，不能换新存储键。
- 原文链接保持目标；精读推荐与当前提供的内容深度分别表达。缩短重复生产说明不等于抹去覆盖限制。

完整阅读卡内容迁移必须先列出当前字段与目标区域，尤其 `learner`、`guidedReading`、`readingActions`、`sections`、`deepRead`、`references`、`openQuestions`、`questions`、`next`。同字段重复描述可合并，任何省略必须解释去向。样稿是选定内容的视觉表达，不能直接把它的简化 renderer 覆盖生产 renderer。

## 5. 路线、书库与首页状态

### 路线

第一屏看到实际起步步骤。左侧顺序列表，右侧当前步骤的目的、阅读重点、自检和阅读入口。默认选中第一步；存在本人在读信息时可提供明确的“继续”入口，不自动判定完成。

“理解课题”承接对象/四轴/演化/比较/证据/开放问题，使用页内可书签状态。`startRoute` 与 `archiveRoute` 同一适配器，旧 `route` 仅兼容输入。左侧序号只表达顺序。每一步都保留 route/track 上下文进入阅读，再原样返回。

“路线下一步”来自当前方向和track；卡内x.next叫“延伸阅读”。没有来路时不猜方向。综述readingPath之外的章节可回结构选择下一节，不跳回路径第一节伪装续读。具体query协议见03。

### 论文与经典

默认主方向起步论文；支持另一方向、拓展/全部与搜索。论文只列一份记录，分组来自路线关系。列表显示题名、简短阅读价值、交付深度和打开入口；重要性/难度详细判断进入阅读卡。

论文标题长时正常换行；价值说明经编辑概括，完整 lead 在卡内。样稿为了覆盖原始长数据，局部使用字符缩略；产品优先采用已审查的短描述，不能全站机械裁断含有限定条件的句子。

经典沿现有 arch/align/reason/agent 分组；不额外建立与研究方向混合的推荐数据库。搜索空结果有明确恢复入口。

5篇基础材料在书库次级“基础导读”分组统一回查，避免首页收拢后遗失入口；各主入口和ID见03。

窄窗口中的图预览必须靠近当前操作：底部可收起短预览/就近展开至少采用一种，不要求滚过完整分组树才找到“阅读本节”。目录、原文定位、记录和历史简报迁到折叠区/正文可达位置，不能用display:none直接取消。桌面优先不等于窄屏可破坏基本阅读。

### 首页

有本人在读标记：可显示明确来自手动记录的继续入口，仍保留栏目用途和全站读法。
无本人记录：建议起点由生效库 startHere推导，不显示虚构今日任务、完成率或连续天数。
导学覆盖层改变了起点/方向数据：首页、路线、列表一致反映生效值。公开快照仅属于本样稿。

## 6. 完成定义

用户可以从首页解释各栏目作用；在综述图说明两篇为何相关；进入一节连续读懂而不跨越多层框；在路线页不滚过研究分析就找到第一步；在库内判断当前应读哪些论文。

“好看”由真实宽度、真实数据和用户使用感受共同确认。编译通过、无控制台错误、截图文件存在，都不足以构成视觉验收通过。
