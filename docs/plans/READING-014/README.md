## 本轮目标

让刚入学的研究生知道要学什么、为什么现在学、如何接着读，并通过充分的中文讲解逐渐获得阅读原文的能力。通过信息归属、空间组织、图文交互和排版共同降低负担。产品实现拟交给用户指定的 Luna；本轮主会话独占设计文件的写入，审查者只读。

## 样稿查看顺序

本机样稿运行时，依次查看：

1. [首页](http://127.0.0.1:4186/#home)：栏目用途、具体起点和双栏布局是否清楚。
2. [综述全景](http://127.0.0.1:4186/#surveys)：点击三篇文章，检查关系能否帮助选读。
3. [ACL文章脉络](http://127.0.0.1:4186/#atlas/survey-agent-evaluation-2026)：选中章节，看关联节点与编号说明，再点“阅读本节”。
4. [主方向路线](http://127.0.0.1:4186/#route/cross-harness-collab)：切换步骤及“理解课题”，判断学习顺序是否明确。
5. [论文库](http://127.0.0.1:4186/#papers)及[经典](http://127.0.0.1:4186/#foundations)：比较扫描列表与简读卡的信息密度。

优先评价三个方面：空间分配、中文连续阅读的舒适度、图是否确实解释了关系。产品的个人记录、导学更新与完整功能兼容将在实施后单独验收。

无需启动预览也可查看v0.3的 [首页截图](previews/v0.3-home-1440.jpg)、[文章内关系截图](previews/v0.3-atlas-1440.jpg)、[长文截图](previews/v0.3-reader-1440.jpg)。全部截图与此前检查范围见REVIEW。

## 样稿运行

在仓库根目录执行：

    node docs/plans/READING-014/prototype/serve.mjs

打开 http://127.0.0.1:4186 。端口占用时停止并换端口，不终止已有进程。
预览进程关闭后需重新执行上述命令。更换端口时用环境变量 `READING_PREVIEW_PORT`，并以控制台打印的地址为准。
样稿只读本目录的公开内容快照，不接入原服务、插件、个人阅读记录或导学覆盖层。页面中的选中表示正在浏览，不表示学习进度。

## 授权与历史衔接

用户已认可v0.2整体设计，仅要求增强配色、按de-ai-flavor减少AI味，并明确不能压缩内容。v0.3落实这两项反馈，后续由Luna按03分阶段实施；本次交付仍为设计与样稿。
PLAN-012 的桌面优先、充分内容、点击图进入独立正文仍有参考价值。其“仅微调首页、固定旧顺序”的历史范围由本轮全面优化需求更新。新设计不把首页压缩成几个空入口；各栏目仍有真实用途、具体材料和学习衔接。
本轮不改研究方向集合、内容事实、来源覆盖级别、旧 ID、个人记录和后端机制。每日精选暂不维护，保留历史入口。旧计划中的实施/测试状态不自动转移到本方案。
