## 原始计划

### 背景与目标

用户 2026-09-24 明确：平台重点**只是**展示综述知识脉络、论文核心线索、技术学习路线，内容要充分展示清楚，其他功能（更新机制、导学提案闭环等）不抢时间。009 里程碑的 known-miss：新增论文 0、方向与技术内容几乎未变、CCF 信息只有目录两个链接——本计划逐项纠偏。

PLAN-010 是**内容展示深化**计划：在不动后端、不动更新机制、不删既有内容的前提下，把首页、综述导学、课题页、论文页、技术路线五处展示面做实，让读者通过站内即可获得「知识从哪来、脉络怎么连、每篇解决什么、技术为什么学」的完整图景。

硬约束（违反即返工）：

1. 保留全部旧论文 ID、v3 笔记、既有内容与方向集合；trusted-rag / graph-harmful-fusion 维持 deferred 不删。
2. 不新增后端、不写路径、不新增更新机制；沿用静态内容模块 + 既有 server 白名单。
3. 不删除 guidance 模块（#/map、#/guidance），仅降为非主入口（首页降为次级链接，内容主入口让位给本计划的展示面）。
4. 新增内容**必须实质落在既有主方向页（cross-harness-collab）与既有论文阅读页**；禁止另开隐藏页面/孤立路由替代主页面更新。
5. 新增论文入库条件：来源核验成功（以 docs/research/guidance-display-source-audit.md 为准）；不得凑数量；deep/standard 必须有正文依据（READING-TEMPLATES-005），无正文依据最多 quick/entry。
6. 排版纪律：清晰、优美、安静的阅读排版；目录、对照表、适量关系图可用；禁止仅堆链接、堆免责声明、堆卡片。
7. 不提交、不推送；删除/覆盖既有资料前必须先检查并取得授权。

### 阶段 D · 论文页三段式导读

- 目标：论文页统一为「先背景术语与读前问题 → 再原文精读定位（章节/图表位置）→ 再实际讲解」三段；首批深做 3 篇基础导读对应的论文 + 综述 2 篇 + 新增 3 篇，其余卡保留原展示不降级。
- 每段要求：背景术语给「读这篇前需要知道的 3–5 个术语」与 2–3 个读前问题；精读定位指到章节/表/图（须有正文依据的卡片才能给定位段）；实际讲解必须是原创解释性文字（Explain 非空，符合 PF-11），禁止复述摘要。
- 预计改动：public/content/papers-*.js（相关卡升档或补导读段）、library.js（三段渲染，按卡是否有依据自动降级为两段并如实标注）。
- 验证：PF-11 断言（Explain 非空或有效 sectionId）；定位段与正文依据一致性抽查；卡片渲染探针。
- 风险：某卡正文依据不足 → 不给定位段，如实标注「定位待核」，不冒充。
