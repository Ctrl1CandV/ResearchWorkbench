# 视觉系统与布局参数

版本：v1.0 · 2026-10-04，设计冻结。参数以已认可 Demo 为基准；参数有效性仍由真实中文画面核对。

## 1. 颜色与面积

建议在现有 `body.lib` 中统一维护语义变量，仍使用原项目作用域。迁移旧 `--lib-*` 时显式映射，不给同一角色留下互相冲突的色值。

| 角色 | 色值 | 用途 |
|---|---|---|
| paper | `#f8f7f3` | 全页暖纸背景 |
| ink | `#243c35` | 主标题、关键语义 |
| body | `#34463f` | 正文、主要说明 |
| muted | `#68716a` | 次要信息，仍须可读 |
| line | `#dadfd5` | 装饰分隔线；不承担必要控件边界 |
| accent | `#235e4c` | 主动作、当前选择、可操作入口 |
| accent-soft | `#e8eee7` | 轻选中背景 |
| figure-surface | `#edf1e9` | 概念图承载区 |
| control-border | `#85917f` | 必要控件边界，实际底色上核对对比 |
| note | `#9d593d` | 编辑提示与章号，不作为错误色 |
| note-surface | `#f1ece2` | 编辑例子或条件说明 |
| next-surface | `#203e33` | 单个主要续读入口 |
| error | `#9b3535` | 明确错误；同时有文字和图标 |

页面大部分保持纸色，深色面积集中在当前选择和主要动作。单页不出现多个等权的大深色卡片。颜色不改变作者结论、编辑解释、来源限制的身份；用标签、线型和文字同时表达。

正文对比至少 4.5:1，大字号文字按适用标准至少 3:1，必要控件边界和焦点至少 3:1。这些是实施时在实际组合上计算的门槛，本设计没有宣称每种组合已经验收。装饰细线不强求与控件相同黑度。

## 2. 字体角色

| 角色 | 栈与字重 | 桌面 / 窄屏 | 行高与用途 |
|---|---|---|---|
| 文章主标题 | Noto Serif CJK SC → Source Han Serif SC → Songti SC → SimSun → serif，700 | 42px / 31px | 1.48–1.5；≥1450 可 46px |
| 一般页面主标题 | 同上，700 | 34–38px / 28–31px | 1.4–1.5 |
| 正文章节 | 同上，600–700 | 27px / 24px | 1.5 |
| 图谱、列表标题 | Microsoft YaHei → PingFang SC → Noto Sans CJK SC → system-ui，600 | 16–20px / 16–18px | 1.5–1.7 |
| 连续正文 | 同黑体栈，400 | 18px / 17px | 1.95；放大档 20px |
| 导语 | 同黑体栈，400 | 17px / 15–16px | 1.9–1.95 |
| 图注、来源和元数据 | 同黑体栈，400 | 12–13px / 12px | 1.65–1.85 |
| 控件 | 同黑体栈，400–600 | 13–14px / 13–14px | 1.5 |
| 章号与少量英文小标 | Georgia → serif | 11–20px，按角色 | 只作层级标记 |

Demo 的装饰小字存在 9–11px 档。迁入正式站时，来源、限制、操作和学习目标不得采用该档；9–11px 仅用于非必要的英文装饰或角标。图谱章节文字按实际显示尺寸至少 14px，目标 16px，不能拿 SVG 内部 font-size 冒充屏幕字号。

本机确认存在 SimSun。不得据此声称其他系统的字体已经验证；没有字体下载时使用系统后备。至少检查长中文题名、中英混排、数字/符号和大字号状态。若宋体在目标系统字重过轻，优先更换标题后备或提高标题对比，正文继续采用黑体。

## 3. 阅读几何

| 场景 | 外框与主栏 | 辅助区 | 让位规则 |
|---|---|---|---|
| 1440×1000 | 外框最大 1216px，内边距 44px；正文最大 790px | 210px；最小间距 72px，多余空间可进入栏间距 | 无固定左侧导航 |
| 1280×900 | 正文以 720–790px 为目标，框内居中 | 184–210px；间距 38–72px | 无法保持正文 640px 时先收起辅助栏 |
| 821–1100px | 页面横边距约 32px，正文弹性 | 可用宽度足够才留 184px 辅助栏 | 不足以放正文至少640px + rail184px + 间距38px时，将同一组件转入流内 |
| ≤820px | 单栏，框最大 748px，横边距 25px | 导语后“目录与阅读设置”展开区 | 不做浮动目录遮正文 |
| ≤480px | 横边距 22px，正文占满可用宽度 | 同上；控件不缩小 | 概念四层变 2×2 |
| ≥1920px | 正文仍最大 790px；整个框居中 | 辅助 210px | 不随屏幕无限拉长文本 |
| 专注模式 | 正文和图保持原最大宽度，主区域居中 | 隐藏目录/旁注，保留退出按钮 | 全站退出路径始终可达 |

1440 阅读正文常规档大致容纳 37–43 个汉字，20px 档约 36–40 字；英文术语、实际字体会改变行长。最终按真实段落判断，不用拉丁 `65ch` 作为中文固定尺寸。无目录、无旁注、没有图的页面都应保持同一正文宽度等级。

只要辅助栏因可用空间、实际字体或缩放退出并排，“目录与阅读设置”立即移到导语后的流内位置；该规则不限于 ≤820px。字号与专注入口不能随侧栏消失。专注态由常显退出按钮提供恢复路径。

实现建议：正文与辅助区使用 `grid-template-areas: 'body rail'`，article 显式绑定 body；没有 rail 时切为单列。禁止依赖 DOM 第一个可见子节点自动落列，特别是空目录被隐藏后的情况。

## 4. 图谱和浏览页几何

- 图谱外框最大 1440px，1440 视口下页面边距 40–44px，无永久左栏。
- 1440 下画布独占一行，选中说明位于下方；≥1600 且画布实际宽度至少 1000px 时允许 300–320px 预览栏并排。
- 初始比例优先让四个主题组在可读字号下出现；不为“全图一次塞进”把节点文字缩到 14px 以下。更大结构允许明确的局部平移与缩放。
- 首页/路线/书库外框最大 1280px；连续介绍最大 44em；列表宽度可更宽。不同页面不强行复用阅读主栏宽度。
- 技术路线正文使用 720–790px 讲解宽度，单位比较或资源列表可占更宽的组内区域；原 `?unit=` 定位仍保留完整路线。

## 5. 间距与容器

统一间距档：4、8、12、16、24、32、48、64px。组内用 8–16px，组件间用 24–32px，章节间用 36–48px，页面大区用 48–64px。响应式允许 22px 页面边距和 Demo 对齐需要的微调，但要记录用途。

- 段落底距 1.25–1.35em；章节标题与正文约 24px。
- 容器圆角 4px；输入与小控件 3px；不用大圆角和药丸形元数据。
- 默认无投影；临时退出按钮可用很轻的单一阴影。持续正文容器不加悬浮卡阴影。
- 边框表达可操作边界和概念分组。普通段落、目录每项、来源每行不各套一个盒子。
- 编辑提示采用左线 + 身份标签 + 轻底；作者结论、待核项的文字标签保持区别。
- 图标以一致的线型 SVG 为主，装饰图标 `aria-hidden`；无文字图标必须有可访问名称。

## 6. 状态与响应式

| 状态 | 视觉与行为 |
|---|---|
| hover | 同角色的背景或文字加深；不改变字号、布局和文字内容 |
| focus-visible | 清楚的 2px 外框和间距；SVG 节点有可见描边 |
| selected/current | 色彩 + 左线/勾选/字重之一；配 aria 属性 |
| disabled | 有具体原因；仍能辨认标签，不靠非常浅的字表示 |
| empty | 说明当前筛选无结果，提供清除/返回；不填假数据 |
| pending | 明确待核原因与可用入口范围，不能呈现可开始按钮 |
| error | 保留输入，错误靠近对象，有恢复动作 |

控件目标区域桌面至少约 36px，手机关键动作至少 44px。字号放大时控件允许增高和换行，不截断标签。`prefers-reduced-motion` 下关闭平滑滚动与非必要过渡。

200% 浏览器缩放需真实核对，窄视口不能替代。400% 下正文应能重排；表格与关系图可在明确区域内二维滚动，但主页面不出现意外横向滚动。

## 7. 防止样式漂移

按“tokens → 壳 → 阅读 → 图谱 → 列表/路线 → 特殊状态 → 响应式”组织 styles.css；整理每个迁移区域的旧重复规则，再建立单一有效定义。不得每阶段在文件末尾不断追加相互覆盖的同名选择器。

禁止全局 `h2`、`button`、`svg text` 规则误伤笔记与导学页；使用角色 class。正文的 `font-size` 必须对列表、callout 和例子有明确继承规则，不能字号按钮只改变第一段。

每一项视觉差异按结构、排版、色彩、细节记录。结构失败先重排，不能靠缩字、负 margin、隐藏长标题或删段落“通过”。
