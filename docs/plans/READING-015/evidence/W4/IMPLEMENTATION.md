- 设计版本：READING-015 v1.0；用户于 2026-10-05 再次确认验收重点为正常桌面/手机窗口中的布局与阅读感受。
- 记录日期：2026-10-05。
- 状态：代表页面正常视图核对完成；本记录不代表所有内容分支或复杂交互矩阵均已通过。

## 本阶段实现

- 将首页分区、方向卡片、起步路线、论文库、经典书目与技术路线索引迁入统一的阅读视觉语言，保留各自真实入口、用途与内容身份。
- 论文条目维持推荐、已交付内容与本人阅读记录之间的区别；经典条目保留摘要级判断，不把建议投入深度呈现为本人已读。
- 延后方向现在有默认收起、可见的入口，继续使用现有记录的标题、说明和 URL；没有并入两条 active 路线。
- 首页仍以当前两条 active 方向、现有精选技术路线及真实页面预览组织入口；没有增加方向、推荐规则或研究内容。
- 起步路线与按需查阅区按用途区分，保留真实 track/step 上下文及旧链接。

主要实现接缝：`public/library.js`、`public/styles.css`。
