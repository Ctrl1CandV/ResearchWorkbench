## 实现内容

- 综述书架卡片和整篇图谱节点按实际题名换行，节点高度随换行变化；不以固定高度或省略号截断题名。
- 桌面整篇图谱把完整关系画布置于主要内容区，所选章节预览在图下方；搜索、分组折叠、关系显示、章节列表、建议读序和真实正文入口仍保留。
- 窄屏综述书架改用可读条目列表；整篇图谱默认章节列表，仍可手动切换至可横向浏览的关系图。
- 领域地图继续从同一份节点/边/路径数据生成关系图、分层列表和预览。学术关系的来源与编辑建议读序的身份分别保留；旧 009 专题关系区仍作为次级区域。
- 综述书架、整篇图谱和地图总览使用无侧栏宽版壳。综述图谱按模型宽度设定画布下限，在窄栏保留 16px 节点文字、由画布自身承接横向滚动，页面本身不横向溢出。
- 桌面领域地图按实际宽版内容栏重排；地图节点文字保持 16px。
- 地图选中节点、读序路径和返回位置使用页面内存与 URL 参数；综述书架选择继续使用其既有的可选 session 视图协议。地图未新增 sessionStorage 键，也没有写入本人阅读状态。

主要实现接缝：public/survey-graph.js、public/surveys.js、public/library.js、public/styles.css。
