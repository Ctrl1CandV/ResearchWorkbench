# 实施计划与任务包

版本：v1.0 · 2026-10-04，设计冻结。本文件用于后续派单；当前任务仅交付设计。实施放行先看 REVIEW，再按以下阶段执行。

## 1. 工作区、角色与交付纪律

工作区固定为 `D:\Program Project\ResearchWorkbench`，起始 Git 基线 `45b45d4`。实施前重新检查 HEAD、工作区差异和内容清单；若基线已变化，先记录差异并复核受影响规格，不回滚用户已有改动。需先读 AGENTS、SPEC、BACKLOG、本包 01–06 与 REVIEW。

主会话负责设计取舍、工作包和最终验收；一个实现者顺序完成重叠文件，独立审查者只读。W1–W5 均触及 styles.css/library.js，禁止同时分给多个写入者。可以并行读取和审查，不并行修改这些文件。

AGENTS 指定 scout=qwen3.8-max、builder=glm-5.3-flash、reviewer=gpt-6-astra。使用命名角色前查宿主可发现性及实际运行元数据；本会话工具未暴露这三个命名角色的发现入口，不能据工具中的普通 agent 名称声称已经找到配置。历史 009 对 general-purpose 的替代授权仅适用于该轮，不自动沿用。本包独立审查若使用显式 gpt-6-astra 协作代理，会如实记录调用方式；它不代表已发现宿主的命名 reviewer。

后续宿主无法发现指定 builder 时，报告会话限制并保留可派发任务包，不能猜模型、冒充指定角色或静默换实现者。主会话在本目录新会话加载角色后继续派单；这不是删除现有成果的理由。

每阶段交付：变更文件清单、内容/行为核对、执行命令及结果、截图索引、独立审查意见闭合、未执行项。证据放在本包的 `evidence/` 下；首次需要时再创建。禁止只写“优化完成”“测试通过”。

## 2. 顺序、门槛与规模

```text
设计独立复核 GO
  → W0 冻结基线
  → W1 正式代表导读 → G1 同内容视觉放行
  → W2 其他阅读形态 → G2 内容/行为/无标题回归
  → W3 图谱/领域/书架 → G3 可读文字和真实交互
  → W4 首页/路线/库 → G4 各类代表页放行
  → W5 特殊页兼容
  → W6 综合验收、修复复核、用户效果确认
```

W1 是首个可看成果，最值得先控制；W2/W3 是主要工作量和回归风险；W4/W5 在已通过的系统上迁移。不得在 W1 未通过时一次改完整站再要求用户判断。

不在未检查实际代码前承诺具体小时数。W0 结束时实现者根据代表页与依赖给出工时区间、风险和是否拆分任务；拆分不能取消下面的出口门槛。进度按已通过的工作包统计。

## W0 · 实施基线与保护清单

**目的**：让后续比较指向同一版产品，区分旧问题与新回归。

**读取**：public 全部相关模块、server/package、相关 tests、Demo、本设计包；不进入 private/.grad。**写入**：仅 `evidence/W0-baseline.md`、公开页面截图与清单；不改产品。

**工作**：

1. 记录 HEAD、工作区已有差异、运行端口和当前实体/路线/单元数；保存公开内容的字段级比较基准。
2. 冻结批准 Demo 的源码和截图 hash（06 的已有 hash 为参照），保留现有文件。
3. 按 06 的代表页矩阵获取正式页基线，特别是无 heading 单元、长论文、图最右组、手机表格。
4. 运行现有测试与综述校验，逐条登记原有失败/跳过。现有测试不是当前通过的既定事实；历史报告数字不能抄成新基线。
5. 建立路由、记录键、导学协议和来源范围保护清单；合成存储回归在隔离 origin 中执行。

**出口 G0**：基线能重放；内容基准、已有失败和禁改范围明确。基线采集受工具阻断时保留未执行状态，不生成假的截图或 GO。

**目的**：用正式渲染还原用户认可的方向，建立后续可复用的壳与阅读组件。

**写入允许**：`public/index.html`、`public/styles.css`、`public/library.js`、`public/content/materials.js` 中唯一代表材料的新增展示字段、`tests/library.test.mjs`/`tests/render.test.mjs` 中相关用例；本阶段证据。**其他内容源、notes/guidance/server 不写**。

**任务**：

- 实现代表材料的稳定块/章节映射及完整回退；新增配置校验，不依赖数组位置。
- 正文、右侧辅助、移动目录、字号与专注、局部来源和文末动作；使用真实原数据及原文末 callout 标题。

**出口 G1**：AC01/03/04/05/07/11/13 及本阶段 AC12/14 项通过；1440/1280/390 实际截图逐项对照 Demo，独立审查无阻断。结构、字体和正文读序达到规格后才进入 W2。所有产品特殊页的最终兼容仍由 W5/W6 完成，不能以抽查代表全站通过。

## 4. 差异与回退

展示配置失效在运行时回退原正文；新样式有阻断可退回该阶段改动，但不删内容、不改记录。回退后补做原流程验证并记录原因。需要覆盖/删除已有资料时按 AGENTS 检查授权，不能由本计划预先授权。
