# 页面规格

版本：v1.0 · 2026-10-04，设计冻结。颜色、尺寸引用 02，行为引用 04，验收编号引用 06。下列线框规定读序与空间关系，不表示新增内容。

## P01 · 材料与论文的连续阅读

代表入口：`#/material/mat-cross-harness-map`。实现接缝：`renderMaterial`、`renderPaper`、`renderLearnerBlock`、`renderReadingActionsBlock`、`renderBlocks`、`renderRail`。

```text
紧凑顶栏：品牌                                     栏目 ▾
真实来路
阅读身份 / 标题 / 导语 / 依据摘要与原文入口
可选概念图：场景 → 机制 → 表示 → 传输
─────────────────────────────────────────────────────
正文：章节标题、论证、例子、局部来源       目录、字号、专注
正文：比较、条件、限制                   阅读目标旁注
正文：自问与掌握目标
完整阅读动作 / 原有延伸阅读
论文：我的记录
来源与覆盖
真实路线的上一/下一步
```

### 页首与第一屏

- 主标题为本页唯一 h1。标题之后直接呈现真实导语和阅读身份；论文作者、年份、类型、交付深度、来源依据仍可查。
- “讲什么 / 为什么读 / 带着什么目的”的完整信息要保留。导语与 gist 重复时可改变位置、减少重复标签，不能删除不同内容；没有 lead 的材料使用其已有 learner.gist，不补写研究事实。
- partial、摘要级和待核的限制在页首常显。长版本、处理日期和完整覆盖列表放在来源详情中；影响解读的限制也保留在相应正文附近。
- 完整阅读动作从密集前置区移到正文相关处或文末。页首显示原 preserve 目标，完整 why 可展开；Explain 的实际讲解必须可读，Skip 的完整理由保留。
- 代表导读的首个正文标题在 1440×1000 默认档、菜单收起时应在 y≤920px；390×844 默认档应在 y≤1180px。按文字全部保留实现，不能以隐藏导语或压缩字号满足阈值。

### 代表导读的专用呈现

按 01 §7 的稳定块映射使用五章：先把场景说清、机制与表示、预算与代价、换手的中性例子、带着问题继续读。章名为展示标题；原段落内的 strong、原末尾 callout 标题与正文保留。

概念图由原比较表生成，不另维护一份抄写数据。四个按钮显示原“层”与“回答的问题”；选择后显示该行的完整例子和“读这一段”按钮。“场景→scene，机制/表示→mechanisms，传输→examples”的解释仅表示本页定位关系，不能绘成论文证明的因果链。

原表的全部列和行仍在“查看完整四层比较”中可展开；辅助图不会替代表内信息。进入正文后，编辑举例邻近例子章节，原 Explain 的 target、why、blocks/sectionId 都能找到。目录来自实际五章，不把表格的四层错当五章。

其他材料没有这张表就不显示概念图，没有章节就连续显示完整“正文”。`availability=pending` 或 `coverage.mode=identity` 时仅显示身份、待核原因、来源与真实路线位置，不能出现五章、掌握目标或“开始读”假动作。

### 四档论文

| 实际交付 | 必须保留的主体 | 不得出现的假象 |
|---|---|---|
| deep | 已有精读章节、先修、条件/局限、问题、引用与读后目标 | 用统一摘要代替深读正文 |
| standard | 已有正文级核心讲解、方法/证据/边界、定位 | 为对齐 deep 增加空章节 |
| quick | 已有速读正文与其真实依据；partial-text 与 abstract 区分 | 统一标“已读全文”或藏起摘要限制 |
| entry | 身份、链接、已有范围说明和可用元数据 | 发明导语、机制图或完整讲解 |

推荐深度与交付深度继续分开。正文目录仅列实际渲染的章节，保留 `sectionAnchorId` 产生的稳定目标；先修、问题、我的记录、来源可作为附加目录项，但不凭空补论文章节。

### 辅助栏与文末

辅助栏只承担目录、设置和短阅读目标。长来源列表、完整路线历史和笔记表单不得挤入 210px 侧栏。常显来源摘要在正文页首；完整来源详情在正文末，并有可操作的页首入口。

论文的本人记录沿用现有组件、字段和读后顺序：正文、读后自问、完整动作及原有延伸阅读之后，来源与覆盖之前。材料与综述单元不新增本人记录。源数据中的 `nextAction` 说明完整保留；显式路线下一步与 `paper.next` 延伸阅读按不同身份显示，细则见 04。文末承载路线前后动作，辅助栏可保留短位置和返回入口，避免重复放两套大续读卡。

移动端，以及任意因空间不足收起侧栏的视口，在导语后放“目录与阅读设置”，展开后包含同一套目录、标准/放大和专注操作；不另造桌面/手机两套可聚焦目录。正文、表格、来源、记录与续读保持完整可达。

## P02 · 综述单元

代表：ACL `survey-scope`（无 heading）、`benchmark-dimensions`（五维图）；FCS `fcs-memory-design`（三轴图）。入口形式 `#/survey/{articleId}/unit/{unitId}`。实现接缝：`surveys.js` 的 `renderUnit`、`renderReadingBlock`、`renderConceptMap`、`bindSurveyToc`。

结构为返回整篇图、题名/出处/导语、真实概念图、阅读意图、连续正文、读序与上一/下一节。采用 P01 的阅读宽度和设置，保留本单元特有的概念图，不强塞代表材料的四层图。

- 原文解释、阅读联系、教学例子维持不同身份；每段现有 locator 与出处就近可展开。单元页首的范围不能代替逐段定位。
- 图选择项、对应正文和选中提示相邻；所有原标签、例子、解释保留。选择改变展示重点，不修改 source 角色或覆盖范围。
- 有 heading 时目录来自 heading；没有 heading 时主正文仍显式占主区域，辅助栏可以仅含设置，不渲染空白目录盒。
- heading 作为滚动目标须能临时聚焦。长标题、formula、list、callout 和比较表完整显示；图和表可局部滚动，段落不可缩成图注。
- session 中有合法 active path 且本单元已由该路径明确进入并记在 readingPathUnitIds 时，直接深链、刷新和 Back/Forward 均保留路径中的位置；未访问的单元不因恰好属于该路径而继承。没有满足条件的路径时显示全单元序列。读序第 n 节是位置，不是本人完成比例。
- 三篇综述仍为 partial；图表视觉核验和独立内容复核的历史开放项不能被本次视觉改造自动消除。

## P03 · 综述书架与单篇内部图

入口：`#/surveys`、`#/survey/survey-agent-evaluation-2026`，及另两篇文章。实现接缝：`renderShelf`、`renderArticleGraph`、`surveyMapState`。

### 书架

```text
标题、当前如何选读、实际范围
三篇综述之间的关系图 / 同源列表
选中文章：它讲什么、已有范围、与另外文章的联系
进入整篇脉络图
候选和来源回查（保留现有内容）
```

三篇真实文章有清楚的题名、年代、当前范围和入口。选中关系说明紧邻图；编辑安排与有来源的文章关系继续标明。候选不伪装成已经完整处理的阅读入口，数量与来源不因布局变化增加。

### 单篇图

```text
题名、导语、范围摘要
操作区：搜索 / 图、列表、读序 / 缩放、复位、关系开关
宽画布：主题组、章节节点、关系
选中章节预览：完整题名、导语、出处、进入正文
建议读序：目标、理由、完整步骤
来源与覆盖
```

- 1440 下预览置于图下。≥1600 且画布实宽≥1000 时可并排，窄屏以同源列表为默认入口；手动选择图后仍可进入画布，不强制切回列表。
- 主题组建议宽 220–260px，实际高度由标题行数与子项决定。节点题名以 16px 为目标，初始实际屏幕字号≥14px；最多行数由内容决定，不做省略号或固定高度裁字。
- 节点尺寸先按真实文字测量/换行确定，再计算连接点。不能在旧固定节点上只放大字号。标题、边和主题组不重叠，最右主题完整可达。
- 四组结构在 1440 默认画布中应能辨认。若图更大，提供明确的局部平移和缩放；不能为一次塞满而把文字缩小。
- 选中预览不截断完整 lead、sourceSections 和当前来源范围；按钮指向该真实单元。图/列表/读序共用当前对象和现有 session 状态。
- 保留现有搜索、折叠主题、关系切换、路径选择、读序说明和复位语义。不能只保留静态好看的图。

## P04 · 首页

入口 `#/home`；实现接缝 `renderHomeReader`、`renderCardGuidanceBanner`、生效库计算。

首页采用横向顶栏、宽介绍和按用途排列的分区；保持现有已实现的阅读动线与分区次序。每个区必须有真实内容预览、用途、主要入口；深色主要动作控制在一处。

| 内容 | 呈现方式 | 保全要求 |
|---|---|---|
| 起步阅读与继续入口 | 宽标题、完整建议理由、明确行动；有手动在读项时按现行规则显示 | 不能自动推断进度；不以匿名百分比代替说明 |
| 综述阅读 | 三篇题名与各自问题、范围；进入书架/文章 | 保留当前真实预览，不只留跳转按钮 |
| 课题深化 | 两条 active 方向的编辑分析与入口 | 主方向、第二方向的顺序和身份不变 |
| 技术学习 | featured 三条路线，必学/按需/浅尝分别显示 | 从现有 helper 得到真实集合，不扩展为十三条等权卡 |
| 经典及精选等既有次级内容 | 紧凑列表/说明，保留原有入口 | 日常感知前沿不变成今日作业 |

相邻分区通过标题、引言和细线区分，不把每个说明段套卡。移动端所有分区单列，菜单在流中展开，完整题名与用途可读。

## P05 · 方向与课题路线

入口 `#/directions`、`#/route/cross-harness-collab`、`#/route/code-agent-verification`。接缝 `renderDirections`、`renderRoute`、`renderRouteTrackView`、`renderDirectionDeepening`。

方向列表突出两条 active 的对象、选择理由、现状日期和限制。两条 deferred 保留明确入口，不因淡化而不可读，也不在首页冒充当前主方向。

路线详情依次为对象与目标、已有起步动线、综述/课题深化、技术能力映射、按需完整谱系；沿用当前 `section=start|topic|archive` 和 step 定位。起步步骤采用一条连续纵向路径：章号、真实题名、用途、阅读目的、交付依据和进入动作，避免反复套大卡。

步骤当前定位不表示完成。外链目录、待核材料、已经交付的正文在可用性上区分；必读说明、Explain 实际讲解、Skip 理由均可回查。完整谱系的栏目可按需展开，但不替代起步路线，也不能删除历史内容。

## P06 · 论文库与经典

入口 `#/papers`、`#/foundations`。接缝 `renderPapers`、`renderSearchablePaperGroups`、`renderFoundations`。

论文库使用搜索/范围控制 + 分组标题 + 连续条目。每项显示完整题名、现有必要元数据、推荐/实际交付的区别、简明用途与真实入口；宽屏可使用主标题列和窄元数据列，手机按条目堆叠。纸色行底、细分隔、明确 hover/focus 足够，不每项加悬浮投影。

筛选状态、计数和分组来自现有生效数据。结果为空提供清除筛选；输入后没有内容不能显示加载占位或旧列表冒充结果。保留现有范围与分组行为，不在本轮新建推荐算法。

经典的 11 个真实条目及各自覆盖/资源说明保留。书/章节/论文身份不混同；没有全文讲解的资源不能因“阅读”按钮而伪装站内完整内容。

## P07 · 技术路线

入口 `#/learn`、`#/learn/tech-multiagent?unit=ma-u1`；同类 RAG、浅图与其他主干。接缝 `renderLearn`、路线详情渲染与 featured helper。

首页三条 featured 大小依用途有区分，但不能把 RAG/图强改成与多智能体同等必学。其他十条主干使用可展开或紧凑列表，仍可进入。

详情为路线目标/为什么学、先修与权限、连续学习单元、真实资源与版本、实践/掌握标准。单元章题和正文采用阅读系统；资源、交付目标、自测、记录本提示和限制不删。`?unit=` 定位目标单元，保持整条路线；来自课题路线的 route/track 上下文带回真实位置。旧 `tech-t4` 读取别名继续指向规范 RAG，不新增重复条目。

## P08 · 领域总览与节点讲解

入口 `#/map`、`#/map?node=land-…`。接缝 `renderLandscape`、`renderLandscapeOverview`、`renderLandscapeLesson`。

总览用宽画布和同源分层列表承载现有层级、支线与路径。学术关系保留来源，建议读序保留编辑理由；旧 009 地图仍作现有次级内容。不能借统一图风格把两套数据合并成一套引用图。

节点讲解使用连续正文、章节和局部来源；保留动机、思想、例子、变化、局限、依据与拓展。从图进来可返回实际 node/path/layout；无来路则显示可靠总览入口。详细教程不塞进节点预览，预览也不能变成只剩标题。

## P09 · 精选、导学与错误页

`#/brief`、`#/brief/{id}`、`#/guidance` 在本轮以公共导航、字体、表单、错误提示兼容为主。精选保留暂停/历史说明和手动发现入口；登记日期、发表日期、整理日期继续区分。自动发现调用规则不变。

导学保留导入、校验、差异预览、显式确认与撤销；长 JSON/错误信息只在局部区域滚动。没有成功导入时不显示成功装饰；改变菜单、窗口、字号时不得清空输入。

不存在的实体、非法 hash/query、存储不可用和发现错误保持明确的现有失败语义。错误页使用正常正文宽度、可读题名和可恢复入口，不能留在上一页的专注态或出现空白壳。
